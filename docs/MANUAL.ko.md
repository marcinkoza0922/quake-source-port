# 사용자 매뉴얼

이 매뉴얼은 이 포트로 Quake를 플레이하는 방법을 다루며, 특히 원작 Quake와
다른 소스 포트에 비해 새로 추가된 기능을 중심으로 설명합니다. 새로운 기능은
모두 선택 사항입니다. 기본 설정에서는 원작 Quake와 똑같이 보이고 플레이됩니다.

## 시작하기

1. Quake 정품을 준비하세요. `QUAKE_BASEDIR` 또는 `-basedir <dir>`로
   `id1/`(그리고 그 옆의 모드들)이 들어 있는 폴더를 포트에 지정합니다.
2. `cargo run --release`를 실행하거나, `-game <dir> +map <map>`으로
   모드를 바로 시작합니다.
3. 설정, 저장 파일, 스크린샷은 모드마다 하나씩
   `~/.local/share/quake-source-port/<game>/` 폴더에 저장됩니다.

메인 메뉴에는 Single Player, Multiplayer, Options, **Help**(이 매뉴얼),
Quit, **맵 팩**이 있으며, 배경에서 Quake 테마가 재생됩니다
(Options → 오디오 → 메인 메뉴 음악). 모든 메뉴는 마우스, 키보드,
컨트롤러, 터치로 조작할 수 있습니다. 항목에 커서를 올리거나 선택하면
설명 툴팁이 나타납니다.

Help에서는 위/아래로 섹션을 고르고, Page Up/Page Down, 왼쪽/오른쪽,
숄더 버튼 또는 텍스트 위에서 마우스 휠로 내용을 스크롤합니다.

## 언어

Options → 게임플레이 → **언어**에서 메뉴, 화면 메시지, 이 매뉴얼의 언어를
고릅니다: 영어, 프랑스어, 독일어, 이탈리아어, 스페인어, 러시아어,
폴란드어, 우크라이나어, 체코어, 슬로바키아어, 크로아티아어, 불가리아어,
스웨덴어, 핀란드어, 덴마크어, 노르웨이어, 네덜란드어, 그리스어,
헝가리어, 루마니아어, 포르투갈어(포르투갈 또는 브라질), 일본어, 한국어,
중국어(간체 또는 번체), 튀르키예어, 인도네시아어, 말레이어, 필리핀어,
베트남어, 세르비아어, 리투아니아어, 라트비아어, 에스토니아어, 몰타어,
알바니아어, 아르메니아어, 조지아어, 아이슬란드어, 아일랜드어, 웨일스어,
바스크어, 카탈루냐어, 갈리시아어, 라틴어, 에스페란토, 벨라루스어,
마케도니아어, 슬로베니아어, 스와힐리어, 아랍어, 히브리어,
페르시아어, 우르두어, 힌디어, 마라티어, 벵골어, 펀자브어,
구자라트어, 타밀어, 텔루구어, 태국어, 크메르어, 암하라어, 광둥어.
**시스템**은 컴퓨터의 언어를 따릅니다. 2021 리마스터 자체의 게임 텍스트는
프랑스어, 독일어, 이탈리아어, 스페인어, 러시아어로만 번역되어 있으며,
다른 언어에서는 영어로 표시됩니다. 클래식 Quake 글꼴에는 악센트 없는
라틴 문자만 있으므로, 영어 이외의 언어에서는 게임 내 작은 글자에 메뉴
글꼴을 사용합니다. 콘솔 메시지는 **콘솔 번역**을 켜지 않으면 영어로
표시됩니다.

## 맵 팩 (모드 브라우저)

메인 메뉴 → 맵 팩에는 설치된 모든 모드와 맵 팩이 설명과 함께 표시됩니다.
하나를 고르면 그 모드로 전환되고, 맵 목록을 둘러보며 아무 맵이나 바로
시작할 수 있습니다. 브라우저는 맵마다 최고 처치 수, 비밀, 시간을
기록합니다. 모드마다 설정을 따로 보관하므로, 한 모드에 맞춘 키 지정과
설정이 다른 모드로 넘어가지 않습니다.

**맵 팩을 두는 곳.** 포트는 Quake 기본 폴더(`id1/`이 있는 폴더,
`QUAKE_BASEDIR` 또는 `-basedir`로 지정)에서 맵 팩을 찾습니다. 그 안에서
게임 데이터(`.pak` 또는 `.pk3` 파일, `progs.dat`, `maps/` 폴더)가 있는
하위 폴더는 모두 목록에 표시됩니다. 따라서 맵 팩은 `id1/` 옆의 별도
폴더에 압축을 풀어 설치합니다. 예: `<basedir>/ad/` 또는
`<basedir>/my_maps/maps/*.bsp`. 필요하면 `title`, `base`, `description`
줄이 담긴 `modinfo.txt`를 추가해 목록에 표시되는 방식을 정할 수 있습니다.
맵 팩은 게임이 시작될 때 검색되므로, 추가한 뒤에는 다시 시작하세요. 각
맵 팩의 저장 파일, 스크린샷, 설정은 맵 팩 폴더가 아니라
`~/.local/share/quake-source-port/<folder>/`에 저장됩니다.

## 분할 화면

한 컴퓨터에서 최대 6명이 협동 또는 데스매치로 플레이할 수 있습니다.

- Multiplayer → New Game → **로컬 플레이어**에서 플레이 인원을 정합니다.
- 플레이어마다 화면, HUD, 사운드, 입력 장치가 따로 있습니다(플레이어
  1은 키보드와 마우스, 나머지는 각자 컨트롤러 하나).
- 화면 배치는 위아래, 좌우, 2×2, 3×2 중에서 고를 수 있습니다
  (`r_splitscreen_layout`).
- 각 플레이어는 Multiplayer → Setup에서 이름과 셔츠/바지 색상을 고릅니다.

## 컨트롤러

이 포트는 게임패드로 플레이하도록 설계되었습니다.

- **무기 휠**(`+weaponwheel`): 누르고 있으면 시간이 느려지고, 어느 스틱이나
  마우스로 무기를 고릅니다. 놓으면 무기가 바뀝니다.
- **조준 보조**(Options → 입력 → 컨트롤러): 적 근처에서의 감속과 적을
  따라가는 회전입니다. 스틱에만 적용되며 마우스에는 절대 적용되지 않습니다.
- **자이로 조준**(Options → 입력 → 컨트롤러 → 자이로): 켜기/끄기와 함께
  좌우(요), 상하(피치), 기울기(롤) 축의 감도를 따로 설정할 수 있습니다
  (기울기는 기본적으로 꺼져 있으며 좌우처럼 시점을 돌리고, 음수 값은
  방향을 반대로 합니다). 노이즈 필터와 자이로 적용 시점(항상, 끔,
  `+gyroaction`을 누르는 동안만)도 설정합니다. **조준 방식**은 오른쪽
  스틱을 2D 조준(시점을 계속 돌림)과 **플릭 스틱**(스틱을 밀면 그 방향으로
  시점이 즉시 돌아가고, 이후 스틱을 돌리면 회전) 사이에서 전환합니다. 둘 다
  자이로와 함께 쓰면 정밀하게 조준할 수 있습니다.
- **진동**, 스틱 감도와 반전.
- **버튼 아이콘**은 사용하는 패드(Xbox, PlayStation, Nintendo)에 맞춰
  자동으로 감지됩니다.
- Options → 조작에서 모든 키를 다시 지정할 수 있으며, 컨트롤러로도
  가능합니다.
- 크기, 불투명도, 시점 속도를 조절할 수 있는 터치스크린 조작.

## 저장

- **자동 저장**은 수동 저장 및 빠른 저장과 따로 순환하므로 직접 저장한
  파일을 덮어쓰지 않습니다. Options → 게임플레이 → 자동 저장 설정에서
  보관 개수와 저장 시점을 고릅니다: 레벨 진입, 타이머, 비밀 하나 또는
  모든 비밀 발견, 적 전멸.
- 불러오기/저장 메뉴의 **저장 카드**에는 각 저장의 레벨, 체력, 아머, 무기,
  열쇠, 처치/비밀 수가 표시됩니다.
- **사망 시**(Options → 게임플레이 → 사망 시) 싱글 플레이에서는 일시 정지
  메뉴에서 무엇을 할지 묻거나, 가장 최근 저장을 불러오거나, 저장을 고르게
  하거나, 레벨을 재시작하도록 할 수 있습니다.

## 게임플레이와 카메라

Options → 게임플레이:

- 시야각 60–130, 걸음 시 화면 흔들림, 무기 반동, 항상 달리기.
- **카메라**: 1인칭, 3인칭, 어깨 너머(오른쪽 또는 왼쪽).
- **무기 모델** 위치: 중앙, 오른쪽, 왼쪽, 숨김.

## 커스터마이즈: 게임 규칙 변경과 애드온

게임은 시작할 때 *기본* 또는 *커스터마이즈* 중 하나로 정해집니다. New
Game(그리고 레벨 선택이나 맵 팩에서 레벨을 고를 때)에서 팝업이 나타납니다.
**플레이**는 게임을 시작하고, **게임 커스터마이즈**는 게임 규칙 변경과
애드온을 엽니다. 무언가를 바꾸면 플레이에 **커스텀** 표시가 붙고,
**모든 변경 끄기**(Del, 게임패드 X 또는 클릭)로 애드온 없는 기본 규칙으로
되돌립니다. 기본 게임은 ironwail과 vkQuake에서도 불러올 수 있는 일반
`.sav` 파일로 저장되고, 커스터마이즈 게임은 이 포트만 불러올 수 있는
`.qsa` 파일로 저장됩니다(다른 포트에서 저장할 수 없는 분할 화면과 협동
게임도 마찬가지입니다). 커스터마이즈 게임 중에는 메인 메뉴 →
커스터마이즈에서 규칙 변경과 애드온을 언제든 바꿀 수 있으며, 기본 게임의
규칙은 고정됩니다. 규칙 변경은 어떤 모드에서도 작동하며 데스매치에서는
꺼집니다.

- 더 어렵게: 받는 피해 증가, 더 강한 적, 탄약과 체력 획득량 감소, 몬스터
  2–4배, 레벨마다 기본 장비로 시작, 수동 저장 금지.
- 더 쉽게: 받는 피해 감소, 더 약한 적, 탄약과 체력 증가, 무한 탄약, 체력
  재생, 낙하 피해 없음, 익사 없음, 자기 피해 없음, 2단 또는 3단 점프.

## 데모

`record <name>`과 `stop`으로 사용자 폴더에 데모를 녹화하고, `playdemo
<name>`으로 재생합니다. 녹화가 끝나면 ironwail과 vkQuake에서도 재생할 수
있도록 데모가 백그라운드에서 다시 쓰입니다. 모드가 다른 포트에서 표시할 수
없는 파티클 효과를 쓰는 경우, 전체 버전은 `<name>.qsd`로 보관됩니다
(`playdemo <name>.qsd`). `demo_convert <name>`은 예전 데모를 변환합니다.

메인 메뉴 → 데모에는 저장한 데모가 나오고, 옵션 → 데모 → 데모 자동 녹화를 켜면 플레이한 모든 레벨의 자동 데모도 나옵니다. 슬롯이 가득 차면 가장 오래된 것부터 교체됩니다. 글자를 입력하면 목록이 걸러지고 Tab으로 정렬 순서를 바꿉니다. 목록 옆의 버튼으로 선택한 데모를 재생, 내보내기, 이름 바꾸기, 보관, 삭제할 수 있으며 자동 데모의 이름을 바꾸면 보관됩니다. 버그 보고서에는 현재 레벨의 자동 데모가 포함됩니다.

데모 재생 중에는 Space로 일시 정지하고, 왼쪽이나 오른쪽을 누르고 있으면 되감기나 빨리 감기를 하며, 위와 아래로 속도를 바꾸고, PgUp과 PgDn으로 10초씩 건너뛰고, Home과 End로 처음과 다음 맵으로 이동합니다. I와 O로 클립 구간을 표시하고, E로 그 클립(또는 데모 전체)을 `videos` 폴더로 내보냅니다.조작 막대는 화면에 계속 표시됩니다. H나 숨기기를 누르면 숨겨지고, 화면 아래 가장자리를 가리키면 다시 꺼낼 수 있는 띠가 나타납니다. 버튼을 클릭하고, 타임라인을 클릭하면 그 위치로 이동하며, 드래그하면 클립을 강조합니다. 내보내기에서는 프레임 속도, 크기, 형식, 파일과 함께 강조한 클립과 데모 전체 중 무엇을 내보낼지 고릅니다.

컨트롤러에서는 A로 일시 정지, 방향 패드로 되감기·빨리 감기·속도 변경, LB와 RB로 10초 이동, 스틱 누르기로 처음과 다음 맵으로 갑니다. LT와 RT로 클립 구간을 표시하고 B로 지우며, X로 내보내고 Y로 자동 데모를 보관하고 View로 조작 막대를 숨깁니다.

`capture`는 플레이 중 비디오 녹화를 시작하고 멈춥니다. 프레임 속도, 형식, 품질은 옵션 → 데모 → 비디오 녹화에 있습니다. 비디오에는 ffmpeg가 필요하며, 없으면 프레임을 PNG 이미지와 WAV 파일로 저장합니다.

## 접근성

Options → 접근성:

- 움직임 줄이기와 화면 번쩍임 강도.
- 색각 이상 필터.
- 조준점 설정: 모양, 크기, 외곽선, 조준 시나 처치 시 색상 변경, 선택 사항인
  히트 마커.
- **사운드 자막**과 메시지 설정(메시지 & 자막), 글자 크기.
- 공격과 달리기를 누르고 있는 대신 전환으로.
- 게임 전체를 느리게 하는 게임 속도 슬라이더.
- 락온 표시기, 포착 범위, 사거리 설정이 있는 자동 조준.

## 향상 기능

Options → 향상 기능. 모두 클라이언트 측에서 작동하며 기본적으로 꺼져
있으므로, 어떤 모드에서도 온라인에서도 쓸 수 있습니다.

- **파편**: 굴러다니는 살점과 부서진 통의 파편으로, 모드의 몬스터에도
  적용됩니다. 문과 승강기에 부딪힐 수도 있습니다.
- **향상된 피 튀김**: 표면의 핏자국, 몸을 따라 움직이는 상처, 떨어진 곳에
  번지는 공중의 핏방울.
- **타격 효과**: 샷건 탄흔, 나무와 적에 박히는 못, 폭발 그을음.
- **향상된 물**: 반투명, 물결, 물보라, 커스틱.
- 목적지를 시차 효과로 보여 주는 **텔레포터 너머 보기**.
- 앰비언트 오클루전, 오브젝트별 모션 블러와 속도 블러, 부드러운 파티클.
- **화면 셰이더**: RetroArch `.slangp` 프리셋(CRT 등).

Options → 그래픽에도 렌더링 배율, 안티에일리어싱, 슈퍼샘플링, 텍스처
필터, 디더링을 곁들인 8비트 색상, 안개, 컬러 조명, 애니메이션/이동 보간 등
일반적인 설정이 있습니다.

## 애드온

애드온은 엔진이 직접 구동하는 새로운 무기와 장비로, 어떤 모드의 progs에서도
작동합니다. 싱글 플레이와 협동에서만 쓸 수 있습니다.

### 애드온으로 게임 시작하기

게임은 애드온을 켜고 시작했을 때만 애드온을 가집니다:

1. Single Player → **애드온** 체크박스를 선택한 뒤 New Game.
2. 가져갈 애드온을 고르고 설정을 조절한 다음 새 게임을 시작합니다.

애드온 게임은 `.sav` 대신 `.qsa` 파일로 저장되므로 다른 포트가 불러오려고
하지 않습니다. 저장 카드에는 "ADD-ONS" 배지가 표시됩니다. 일반 저장을
불러오면 애드온이 꺼집니다. 애드온 게임을 플레이하는 동안에는 애드온
페이지(콘솔: `menu_options addons`)에서 개별 애드온을 켜고 끌 수 있으며,
각각 반복 재생되는 미리 보기, 설명, 키 지정, 자체 설정이 있습니다.

### 무기

애드온은 일반 무기 슬롯(애드온마다 고르거나 슬롯 9와 0)에 들어가며 무기
휠과 HUD에 표시됩니다. 사격과 보조 사격은 평소의 공격 버튼입니다.

| 애드온 | 사격 | 보조 사격 | 탄약 |
|---|---|---|---|
| **포털 건** | 파란 포털 설치 | 주황 포털 설치 | 없음 |
| **레일건** | 직선상의 모든 것을 맞히는 관통 탄환 | — | 셀 2개 |
| **훅샷** | 나무, 금속, 돌, 적에 걸어 그쪽으로 끌려감 | — | 없음 |
| **점착 폭탄 발사기** | 누르고 있으면 충전, 놓으면 발사 | 폭파 | 로켓 1개 |
| **부메랑** | 누르고 있으면 적을 지정, 놓으면 던짐; 차례로 기절시킴 | 지정 해제 | 없음 |
| **젤 분사기** | 파란 반발 젤 (튕김) | 주황 추진 젤 (빠름) | 없음 |
| **고압 세척기** | 적을 밀어내고 젤을 씻어 내는 긴 물줄기 | 넓은 부채꼴 물줄기 | 없음 |

포털은 월드의 평평한 표면에 설치되며, 플레이어와 몬스터, 던진 물체를
운동량 그대로 통과시킵니다. **포털 너머 보기**를 켜면 반대편이 실시간으로
보이며, 포털 너머로 보이는 포털도 표시됩니다. 품질, 실시간 화면 수, 거리,
재귀 깊이를 조절할 수 있습니다.

## 멀티플레이

LAN과 인터넷 NetQuake 플레이(프로토콜 15, 666, 999) 외에도 이 포트는
**QuakeWorld** 서버에 접속할 수 있습니다. Multiplayer → Join Game에서
주소를 입력하거나 LAN을 검색합니다. FTE 스크립트 파티클을 쓰는 모드도
지원합니다.

## 명령줄과 콘솔

자주 쓰는 옵션: `-basedir <dir>`, `-game <dir>`, `-hipnotic` / `-rogue` /
`-quoth`, `-width <w>`, `-height <h>`, `-fullscreen`, `-window`, 그리고
시작할 때 콘솔 명령을 실행하는 `+command args`. 콘솔(`~`)에서는 일반적인
Quake 명령과 cvar를 쓸 수 있습니다.
