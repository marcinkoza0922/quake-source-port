# მომხმარებლის სახელმძღვანელო

ეს სახელმძღვანელო აღწერს Quake-ის თამაშს ამ პორტით, უპირველეს ყოვლისა
იმას, რასაც ის ორიგინალურ Quake-სა და სხვა პორტებს ამატებს. ყველაფერი
ახალი არასავალდებულოა: ნაგულისხმევი პარამეტრებით თამაში ისე გამოიყურება
და ისე თამაშდება, როგორც Quake.

## დაწყება

1. შეიძინეთ Quake-ის საკუთარი ასლი. მიუთითეთ პორტს საქაღალდე, რომელიც
   შეიცავს `id1/`-ს (და მის გვერდით მოდებს), `QUAKE_BASEDIR`-ით ან
   `-basedir <dir>`-ით.
2. გაუშვით `cargo run --release`, ან პირდაპირ გაუშვით მოდი
   `-game <dir> +map <map>`-ით.
3. კონფიგურაცია, შენახვები და ეკრანის სურათები ინახება
   `~/.local/share/quake-source-port/<game>/`-ში, თითო საქაღალდე თითო მოდზე.

მთავარ მენიუში არის Single Player, Multiplayer, Options, **Help** (ეს
სახელმძღვანელო), Quit და **რუკების პაკეტები**, ფონზე კი Quake-ის თემა
ჟღერს (Options → აუდიო → მთავარი მენიუს მუსიკა). ყველა მენიუ მუშაობს
მაუსით, კლავიატურით, კონტროლერით და სენსორით; მიიტანეთ კურსორი ან
აირჩიეთ პარამეტრი, რომ ნახოთ მისი ამხსნელი მინიშნება.

დახმარებაში ზემოთ/ქვემოთ ირჩევს განყოფილებას; Page Up/Page Down,
მარცხნივ/მარჯვნივ, მხრის ღილაკები ან მაუსის ბორბალი ტექსტზე მას
გადაახვევს.

## რუკების პაკეტები (მოდების ბრაუზერი)

მთავარი მენიუ → რუკების პაკეტები ჩამოთვლის ყველა დაყენებულ მოდსა და
რუკების პაკეტს აღწერით. აირჩიეთ რომელიმე მასზე გადასასვლელად, შემდეგ
დაათვალიერეთ მისი რუკები და პირდაპირ დაიწყეთ ნებისმიერი. ბრაუზერი
თითოეულ რუკაზე იმახსოვრებს თქვენს საუკეთესო მოკვლებს, საიდუმლოებს და
დროს. თითოეულ მოდს საკუთარი კონფიგურაცია აქვს, ასე რომ ერთი მოდისთვის
მორგებული მინიჭებები და პარამეტრები მეორეში არ გადადის.

**სად თავსდება რუკების პაკეტები.** პორტი მათ Quake-ის საბაზო
საქაღალდეში ეძებს (იმაში, სადაც `id1/` არის, მითითებული
`QUAKE_BASEDIR`-ით ან `-basedir`-ით). იქ ყოველი ქვესაქაღალდე, რომელიც
თამაშის მონაცემებს შეიცავს (`.pak` ან `.pk3` ფაილს, `progs.dat`-ს ან
`maps/` საქაღალდეს), სიაში ჩანს, ამიტომ რუკების პაკეტი დააყენეთ მისი
საკუთარ საქაღალდეში გახსნით `id1/`-ის გვერდით, მაგალითად
`<basedir>/ad/` ან `<basedir>/my_maps/maps/*.bsp`. სურვილისამებრ
დაამატეთ `modinfo.txt` სტრიქონებით `title`, `base` და `description`,
რომ განსაზღვროთ, როგორ გამოჩნდეს ის სიაში. პაკეტები თამაშის გაშვებისას
მოიძებნება, ამიტომ დამატების შემდეგ თამაში თავიდან გაუშვით. თითოეული
პაკეტის შენახვები, ეკრანის სურათები და კონფიგურაცია ინახება
`~/.local/share/quake-source-port/<folder>/`-ში და არა პაკეტის
საქაღალდეში.

## გაყოფილი ეკრანი

ექვს მოთამაშემდე ერთ კომპიუტერზე, კოოპერატივში ან deathmatch-ში.

- Multiplayer → New Game → **ლოკალური მოთამაშეები** ადგენს, რამდენი
  ადამიანი თამაშობს.
- თითოეულ მოთამაშეს აქვს საკუთარი ხედი, HUD, ხმა და შეყვანის მოწყობილობა
  (კლავიატურა და მაუსი პირველი მოთამაშისთვის, თითო კონტროლერი
  დანარჩენებისთვის).
- ეკრანის განლაგება შეიძლება იყოს ერთმანეთზე, გვერდიგვერდ, 2×2 ან 3×2
  (`r_splitscreen_layout`).
- თითოეული მოთამაშე სახელს და პერანგის/შარვლის ფერებს ირჩევს
  Multiplayer → Setup-ში.

## კონტროლერები

პორტი გეიმპადით სათამაშოდაა შექმნილი.

- **იარაღის ბორბალი** (`+weaponwheel`): დაიჭირეთ დროის შესანელებლად და
  აირჩიეთ იარაღი რომელიმე სტიკით ან მაუსით; გაუშვით გადასართავად.
- **დამიზნების დახმარება** (Options → შეყვანა → კონტროლერი): შენელება
  მტრებთან ახლოს და მობრუნება, რომელიც მათ მიჰყვება. ის მხოლოდ სტიკზე
  მოქმედებს და არასოდეს მაუსზე.
- **გიროსკოპით დამიზნება** (Options → შეყვანა → კონტროლერი →
  გიროსკოპი): გადამრთველი, ცალკე მგრძნობელობა ჰორიზონტალური,
  ვერტიკალური და გადახრის ღერძებისთვის (გადახრა ნაგულისხმევად
  გამორთულია და ხედს ჰორიზონტალურის მსგავსად აბრუნებს, უარყოფითი
  მნიშვნელობები მიმართულებას ცვლის), ხმაურის ფილტრი და როდის მოქმედებს
  გიროსკოპი (ყოველთვის, გამორთულია ან მხოლოდ `+gyroaction`-ის
  დაჭერისას). **დამიზნების სტილი** მარჯვენა სტიკს გადართავს 2D
  დამიზნებასა (ხედს შეუფერხებლად აბრუნებს) და **ფლიკ-სტიკს** შორის
  (გადახარეთ სტიკი, რომ ხედი მაშინვე იმ მიმართულებით შემობრუნდეს, შემდეგ
  სტიკის ბრუნვით ატრიალეთ); ორივე კარგად ერწყმის გიროსკოპს ზუსტი
  დამიზნებისთვის.
- **ვიბრაცია**, სტიკის მგრძნობელობა და ინვერსია.
- **ღილაკების ხატულები** შეესაბამება თქვენს პადს (Xbox, PlayStation,
  Nintendo) და ავტომატურად ამოიცნობა.
- ყველაფრის გადანიშვნა შესაძლებელია Options → მართვაში, კონტროლერიდანაც.
- სენსორული მართვა რეგულირებადი ზომით, გაუმჭვირვალობით და ხედის
  სიჩქარით.

## შენახვა

- **ავტოშენახვები** ხელით შენახვებისა და სწრაფი შენახვებისგან ცალკე
  ბრუნავს, ასე რომ თქვენსას არასოდეს გადაწერს. Options → გეიმპლეი →
  ავტოშენახვის პარამეტრები ირჩევს, რამდენი შეინახოს და როდის: დონეზე
  შესვლისას, ტაიმერით, საიდუმლოს ან ყველა საიდუმლოს პოვნისას და ყველა
  მტრის მოკვლისას.
- **შენახვის ბარათები** ჩატვირთვისა და შენახვის მენიუებში აჩვენებს
  თითოეული შენახვის დონეს, ჯანმრთელობას, ჯავშანს, იარაღს, გასაღებებს და
  მოკლულებს/საიდუმლოებს.
- **სიკვდილისას** (Options → გეიმპლეი → სიკვდილისას) ერთმოთამაშიან
  თამაშს შეუძლია შეჩერებულ მენიუში გკითხოთ, რა გააკეთოს, ჩატვირთოს ბოლო
  შენახვა, მოგცეთ შენახვის არჩევის საშუალება ან დონე თავიდან დაიწყოს.

## გეიმპლეი და კამერა

Options → გეიმპლეი:

- ხედვის არე 60–130, ხედის რხევა, იარაღის უკუცემა, მუდამ სირბილი.
- **კამერა**: პირველი პირიდან, მესამე პირიდან ან მხრიდან (მარჯვენა ან
  მარცხენა).
- **იარაღის მოდელების** პოზიცია: ცენტრი, მარჯვნივ, მარცხნივ ან დამალული.

## მორგება: თამაშის მოდიფიკატორები და დამატებები

თამაში ან *ორიგინალურია*, ან *მორგებული*, რაც დაწყებისას ირჩევა. New
Game (და დონის არჩევა „დონის არჩევაში“ ან რუკების პაკეტებში) აჩენს
ფანჯარას: **თამაში** იწყებს თამაშს, **გამოცდილების მორგება** ხსნის
თამაშის მოდიფიკატორებს და დამატებებს. სანამ რამე შეცვლილია, „თამაშს“
აქვს ნიშანი **მორგებული**, ხოლო **ყველა ცვლილების გამორთვა** (Del,
გეიმპადის X ან დაწკაპუნება) აბრუნებს სტანდარტულ წესებს დამატებების
გარეშე. ორიგინალური თამაშები ინახება ჩვეულებრივ `.sav` ფაილებად,
რომლებსაც ironwail და vkQuake ტვირთავს; მორგებული თამაშები ინახება
