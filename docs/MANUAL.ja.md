# ユーザーマニュアル

このマニュアルでは、このソースポートでQuakeを遊ぶ方法を、特にオリジナルのQuakeや他のソースポートにない追加機能を中心に説明します。新機能はすべて任意です。初期設定のままなら、見た目も遊び心地もQuakeそのものです。

## はじめに

1. Quakeを各自で用意してください。`QUAKE_BASEDIR`または`-basedir <dir>`で、`id1/`（とその隣に置いたMOD）を含むフォルダーを指定します。
2. `cargo run --release`を実行するか、`-game <dir> +map <map>`でMODを直接起動します。
3. 設定、セーブ、スクリーンショットは`~/.local/share/quake-source-port/<game>/`にMODごとのフォルダーで保存されます。

メインメニューにはSingle Player、Multiplayer、Options、**Help**（このマニュアル）、Quit、**マップパック**があり、背景でQuakeのテーマが流れます（Options → オーディオ → メインメニューBGM）。すべてのメニューはマウス、キーボード、コントローラー、タッチで操作できます。項目にカーソルを合わせるか選択すると、説明のツールチップが表示されます。

Helpでは上下キーで章を選びます。Page Up/Page Down、左右キー、ショルダーボタン、テキスト上のマウスホイールでスクロールします。

## 言語

Options → ゲームプレイ → **言語**で、メニュー、画面メッセージ、このマニュアルの言語を選びます：英語、フランス語、ドイツ語、イタリア語、スペイン語、ロシア語、ポーランド語、ウクライナ語、チェコ語、スロバキア語、クロアチア語、ブルガリア語、スウェーデン語、フィンランド語、デンマーク語、ノルウェー語、オランダ語、ギリシャ語、ハンガリー語、ルーマニア語、ポルトガル語（ポルトガル・ブラジル）、日本語、韓国語、中国語（簡体字・繁体字）、トルコ語、インドネシア語、マレー語、フィリピノ語、ベトナム語、セルビア語、リトアニア語、ラトビア語、エストニア語、マルタ語、アルバニア語、アルメニア語、ジョージア語、アイスランド語、アイルランド語、ウェールズ語、バスク語、カタルーニャ語、ガリシア語、ラテン語、エスペラント語、ベラルーシ語、マケドニア語、スロベニア語、スワヒリ語、アラビア語、ヘブライ語、ペルシア語、ウルドゥー語、ヒンディー語、マラーティー語、ベンガル語、パンジャブ語、グジャラート語、タミル語、テルグ語、タイ語、クメール語、アムハラ語、広東語。**システム**はコンピューターの言語に従います。2021年リマスター版独自のゲーム内テキストはフランス語、ドイツ語、イタリア語、スペイン語、ロシア語にのみ翻訳されており、その他の言語では英語で表示されます。英語以外の言語では、クラシックなQuakeフォントがアクセントなしのラテン文字しか持たないため、ゲーム内の小さな文字にもメニューフォントを使います。**コンソールを翻訳**をオンにしない限り、コンソールメッセージは英語のままです。

## マップパック（MODブラウザー）

メインメニュー → マップパックには、インストール済みのすべてのMODとマップパックが説明付きで一覧表示されます。1つ選ぶとそれに切り替わり、そのマップを閲覧して好きなマップを直接開始できます。ブラウザーはマップごとのキル数、シークレット、タイムの最高記録を記録します。MODごとに設定が独立しているため、あるMOD用に調整した割り当てや設定が他のMODに影響することはありません。

**マップパックの置き場所。** ソースポートはQuakeのベースフォルダー（`id1/`を含むフォルダー。`QUAKE_BASEDIR`または`-basedir`で指定）からマップパックを探します。そこにあるゲームデータ（`.pak`や`.pk3`ファイル、`progs.dat`、`maps/`フォルダー）を含むサブフォルダーがすべて一覧に表示されます。マップパックは`id1/`の隣にある専用フォルダーに展開してインストールしてください。例：`<basedir>/ad/`、`<basedir>/my_maps/maps/*.bsp`。必要なら`title`、`base`、`description`の行を書いた`modinfo.txt`を追加して、表示方法を調整できます。マップパックはゲーム起動時に検出されるため、追加したら再起動してください。各パックのセーブ、スクリーンショット、設定はパックのフォルダーではなく`~/.local/share/quake-source-port/<folder>/`に保存されます。

## 画面分割

1台のマシンで最大6人まで、協力プレイまたはデスマッチで遊べます。

- Multiplayer → New Game → **ローカルプレイヤー**で人数を設定します。
- 各プレイヤーは専用の視点、HUD、サウンド、入力デバイスを持ちます（プレイヤー1はキーボードとマウス、それ以外は各自コントローラー）。
- 画面配置は縦積み、横並び、2×2、3×2から選べます（`r_splitscreen_layout`）。
- 各プレイヤーはMultiplayer → Setupで名前とシャツ・ズボンの色を選びます。

## コントローラー

このソースポートはゲームパッドでのプレイを前提に設計されています。

- **武器ホイール**（`+weaponwheel`）：長押しすると時間が遅くなり、どちらかのスティックかマウスで武器を選び、離すと持ち替えます。
- **エイムアシスト**（Options → 入力 → コントローラー）：敵の近くでの減速と、敵を追う回転。スティックにのみ働き、マウスには一切働きません。
- **ジャイロエイム**（Options → 入力 → コントローラー → ジャイロ）：オン・オフに加え、ヨー、ピッチ、ロール各軸の個別感度（ロールは初期設定でオフ、ヨーと同様に視点を回し、負の値で反転）、ノイズフィルター、ジャイロが働くタイミング（常時、`+gyroaction`長押し中はオフ、長押し中のみ）を設定できます。**エイム方式**で右スティックを2Dエイム（視点を連続回転）と**フリックスティック**（倒した方向へ視点を即座に向け、その後スティックを回すと視点が回転）に切り替えます。どちらもジャイロと組み合わせて細かく狙えます。
- **振動**、スティック感度と反転。
- **ボタンアイコン**はお使いのパッド（Xbox、PlayStation、Nintendo）に合わせて自動検出されます。
- Options → 操作ですべてを再割り当てできます。コントローラーからも操作可能です。
- タッチスクリーン操作はサイズ、不透明度、視点速度を調整できます。

## セーブ

- **オートセーブ**は手動セーブやクイックセーブとは別にローテーションするため、自分のセーブを上書きすることはありません。Options → ゲームプレイ → オートセーブ設定で保持数とセーブのタイミングを選べます：レベル開始時、一定間隔、シークレット発見時または全シークレット発見時、敵全滅時。
- ロード・セーブメニューの**セーブカード**には、各セーブのレベル、体力、アーマー、武器、鍵、キル数・シークレット数が表示されます。
- **死亡時**（Options → ゲームプレイ → 死亡時）、シングルプレイでは一時停止メニューで対応を尋ねる、最新のセーブをロードする、セーブを選ぶ、レベルをやり直す、のいずれかを選べます。

## ゲームプレイとカメラ

Options → ゲームプレイ：

- 視野角60〜130、視点の揺れ、射撃反動、常に走る。
- **カメラ**：一人称、三人称、または肩越し（右か左）。
- **武器モデル**の位置：中央、右、左、非表示。

## カスタマイズ：ゲームプレイ調整とアドオン

ゲームは開始時に*バニラ*か*カスタマイズ*のどちらかに決まります。ニューゲーム（およびレベル選択やマップパックでのレベル選択）ではポップアップが表示されます。**プレイ**でゲームを開始し、**ゲーム体験をカスタマイズ**でゲームプレイ調整とアドオンを開きます。何か変更していると、プレイに**カスタム**の表示が付き、**すべての変更を無効化**（Del、ゲームパッドのX、またはクリック）でアドオンなしの標準ルールに戻ります。バニラのゲームはironwailやvkQuakeでもロードできる通常の`.sav`ファイルでセーブされます。カスタマイズしたゲームはこのソースポートでのみロードできる`.qsa`ファイルでセーブされます（他のソースポートではセーブできない画面分割や協力プレイも同様です）。カスタマイズしたゲーム中は、メインメニュー → カスタマイズでいつでも調整とアドオンを変更できます。バニラのゲームのルールは固定です。調整はどのMODでも機能し、デスマッチでは無効になります。

- 難しく：被ダメージ増加、敵の強化、弾薬・体力アイテムの減少、モンスター2〜4倍、毎レベルのピストルスタート、手動セーブなし。
- 易しく：被ダメージ減少、敵の弱体化、弾薬・体力の増加、弾薬無限、体力回復、落下ダメージなし、溺れない、自爆ダメージなし、2段・3段ジャンプ。

## デモ

`record <name>`と`stop`でユーザーフォルダーにデモを録画し、`playdemo <name>`で再生します。録画を止めると、ironwailやvkQuakeでも再生できるようにデモがバックグラウンドで書き直されます。MODが他のソースポートで表示できないパーティクルエフェクトを使っている場合、完全版は`<name>.qsd`として残ります（`playdemo <name>.qsd`）。`demo_convert <name>`で古いデモを変換します。

## アクセシビリティ

Options → アクセシビリティ：

- 動きの抑制と画面フラッシュの強さ。
- 色覚補正フィルター。
- カスタマイズ可能なクロスヘア：形、サイズ、縁取り、照準時やキル時の色変更。任意でヒットマーカー。
- **効果音字幕**とメッセージ設定（メッセージ＆字幕）、文字サイズ。
- 攻撃と走りの切り替え式（長押しの代わり）。
- ゲーム全体を遅くするゲーム速度スライダー。
- ロック表示、捕捉範囲、射程を設定できるオートエイム。

## 強化

Options → 強化。すべてクライアント側で動作し初期設定ではオフなので、どのMODでもオンラインでも使えます。

- **破片**：転がる肉片や壊れた樽から飛ぶ榴散弾。MODのモンスターにも対応し、ドアやリフトにぶつかることもあります。
- **強化血しぶき**：面に飛び散る血、体に追従する傷、着地した場所に広がる空中の飛沫。
- **着弾エフェクト**：ショットガンの弾痕、木や敵に刺さるネイル、爆発の焦げ跡。
- **強化水面**：半透明、波紋、水しぶき、コースティクス。
- 視差付きで行き先を映す**透けるテレポーター**。
- アンビエントオクルージョン、オブジェクト単位とスピードのモーションブラー、ソフトパーティクル。
- **画面シェーダー**：RetroArchの`.slangp`プリセット（CRTなど）。

Options → グラフィックには、おなじみのレンダースケール、アンチエイリアス、スーパーサンプリング、テクスチャフィルター、ディザリング付き8ビットカラー、フォグ、カラーライティング、アニメーション・移動補間もあります。

## アドオン

アドオンはエンジンが動かす新しい武器と装備で、どのMODのprogsでも動作します。シングルプレイと協力プレイ専用です。

### アドオン付きでゲームを始める

ゲームにアドオンが入るのは、アドオン付きで開始した場合だけです：

1. Single Player → **アドオン**のチェックボックスをオンにして、New Gameを選びます。
2. 持ち込むアドオンを選んで設定を調整し、ゲームを開始します。

アドオン付きのゲームは`.sav`ではなく`.qsa`ファイルでセーブされるため、他のソースポートがロードしようとすることはありません。セーブカードには「ADD-ONS」のバッジが付きます。通常のセーブをロードするとアドオンはオフになります。アドオン付きのゲーム中は、アドオンページ（コンソール：`menu_options addons`）で個々のアドオンをオン・オフできます。各アドオンにはループするプレビュー、説明、割り当て、専用の設定があります。

### 武器

アドオンは通常の武器スロットに入り（アドオンごとにスロットを選ぶか、スロット9と0）、武器ホイールとHUDに表示されます。射撃とサブ射撃はいつもの攻撃ボタンです。

| アドオン | 射撃 | サブ射撃 | 弾薬 |
|---|---|---|---|
| **ポータルガン** | 青いポータルを設置 | オレンジのポータルを設置 | なし |
| **レールガン** | 直線上のすべてを貫く弾 | — | セル2 |
| **フックショット** | 木、金属、石、敵に引っ掛けて自分を引き寄せる | — | なし |
| **粘着爆弾ランチャー** | 長押しでチャージ、離して発射 | 起爆 | ロケット1 |
| **ブーメラン** | 長押しで敵をマーク、離して投げる。順にスタンさせる | マーク解除 | なし |
| **ジェル噴射器** | 青い反発ジェル（跳ねる） | オレンジの推進ジェル（速い） | なし |
| **高圧洗浄機** | 敵を押しジェルを洗い流す長い水流 | 扇状に広がる水流 | なし |

ポータルはワールドの平らな面に設置でき、プレイヤー、モンスター、投げた物体を勢いを保ったまま通します。**ポータル越しに見る**をオンにすると、ポータルの向こう側がリアルタイムで見えます（ポータル越しに見えるポータルも含む）。品質、ライブ映像の数、距離、再帰の深さは調整できます。

### 装備

装備は手に持つのではなく、オン・オフで切り替えます。**装備ホイール**（`+equipwheel`）を開くか、`goggles cycle`で順に切り替えます：

- **暗視**
- **サーマル**

## マルチプレイ

LANとインターネットでのNetQuakeプレイ（プロトコル15、666、999）に加え、**QuakeWorld**サーバーにも接続できます。Multiplayer → Join Gameでアドレスを入力するか、LANを検索します。FTEのスクリプトパーティクルを使うMODにも対応しています。

## コマンドラインとコンソール

よく使うオプション：`-basedir <dir>`、`-game <dir>`、`-hipnotic` / `-rogue` / `-quoth`、`-width <w>`、`-height <h>`、`-fullscreen`、`-window`、起動時にコンソールコマンドを実行する`+command args`。コンソール（`~`）では通常のQuakeコマンドとcvarが使えます。
