# First full perfkit run: the P4 baseline (2026-11-21)

Results and every detail behind them, for the lean plan in
[PLAN.md](PLAN.md). Tooling: DESIGN.md (Tooling: `perfkit run`).
Commit `7f66f0f` (branch `feature/perf-plan-runner`), clean tree.

## Machine

NVIDIA GeForce RTX 3060 Ti (driver 620.70.06), 12th Gen Intel(R) Core(TM) i7-12700K, kernel 7.3.4-202.nobara.fc44.x86_64, CPU powersave/performance (performance), gamescope 3.16.23.2+, MangoHud v0.8.4, commit 7f66f0f

CPU governor `performance`. No other GPU load; one engine process at a
time. Display output for gamescope: 2560×1440.

## What was run

`target/release/perfkit run -full`: 30 scenes (all but `hdr-deluxe`), 55
distinct runs × 2 resolutions × 3 rounds = 330 timed runs, plus one
discarded warm-up per game and resolution and one attribution run per demo
run and resolution. 71 minutes (plan target: 30). No run failed, no config
changed, no frame over 33 ms in any run.

### Method

- **Engine**: ours only, release build, sandbox from perfkit (empty user
  config under `target/perf/userdata`, `+sv_autosave 0`), every engine
  process SIGKILLed so no config is written.
- **Resolutions**: 960×540 in a window (CPU-bound) and 3840×2160 inside
  gamescope (GPU-bound), vsync off.
- **Settings**: Part 1's "vanilla ultra" pins (`perfkit settings`: 8×
  MSAA, 16× anisotropy, classic filter, render scale 1, remaster models,
  lerping, dynamic lights, `.lit`, fog) plus `perfkit::plan::PLAN_OFF`,
  which pins every plan feature off at its default tier. FTE demo scenes
  use the `ultra-fte` profile. A scene's "on" adds its feature cvars at
  the default tier; "top" adds the top-tier cvars on top.
- **Demo scenes**: timedemos of `perfkit record` demos (`07b9663-dirty`
  set, recorded headless at 250 Hz: spins 240 game s, ~15000 frames;
  combat 120 s, ~7500 frames). Frame times from MangoHud, the first 125
  frames (2 game s) left out. GPU time from a separate attribution run
  with `prof_timedemo` (engine profiler), whose timing isn't used.
- **Live scenes**: the map started by script with `-fixedstep 250` and
  `host_maxfps 10000`, `god` and `notarget` at 2 s, the camera placed at
  2.5 s (`freecam`, or `setpos` when the player acts), timed setup
  commands, engine profiler from 5 s to 20 s. Mean = wall time per frame;
  p50/p99/max/hitches from host frame times; GPU µs per frame from the
  profiler's timestamps. Audio scenes run in real time instead of
  fixed-step. Off and on share the script; only the pins differ (with an
  add-on off its `toy` and `goggles` commands do nothing, and
  `portal_set` makes no visible portals outside a customized game,
  checked with screenshots).
- **Rounds** are interleaved (every run once per round). Cost = median
  mean frame time on minus off. **Significant** = differs by more than 3%
  and by more than the larger spread (max − min of the 3 runs).

## Findings

### Costs that matter (4K, GPU)

1. **SSAO at the top tier** (`r_ssao 3`): +5975 µs, the 4K frame from
   1.43 to 7.41 ms (p99 11.75 ms). The default tier costs +900 µs. By far
   the most expensive single setting.
2. **Bloom**: +1554 µs, more than doubling the 4K frame (+109%). Only
   +89 µs at 540p, so it scales with pixels much more than expected for a
   downsampled effect.
3. **Ray-traced water reflections**: +1168 µs at 4K and +212 µs at 540p
   (the 540p cost suggests per-frame CPU work too: TLAS updates?).
4. Water droplets +429 µs; portal recursion 6 +394; teleporter windows
   +369; real-time dlights top +325; cable +274; planar reflections +264.

### Costs that matter (540p, CPU)

Ray-traced water +212 µs, portal gun at recursion 6 +158, teleporter
windows +141, SSAO top +140, bloom +89, real-time dlights +52–59,
enhanced particles +58, cable +56.

### Cheap or within noise

Water refraction, the other water effects, sky wind, washer (+64 µs at
4K), motion blur (+113 µs at 4K), goggles (+107 to +220 µs at 4K only),
`r_water_quality 2` (changes no water cost).

### Everything on

all-split4: 1.60 → 4.29 ms at 540p, 2.50 → 8.33 ms at 4K (120 fps); GPU
2.3 → 8.2 ms; p99 3.94 → 11.85 ms. No excess figure yet: the
single-feature costs come from other maps and views, so their sum isn't
comparable. Leave-one-out runs on this scene are the next step.

### Suspicious results

- **Blood, impacts, debris** cost at most +74 µs at 4K and ~0 at 540p on
  the combat demo, in a rocket fight. These effects may not replay from a
  demo at all (PLAN P3). If not, these scenes move to a live fight like
  the audio ones.
- **Audio** shows no main-thread cost; mixing has its own thread. Needs
  the P2 counters (mixer time per buffer, probe time, underruns).
- **ad_sepulcher live** costs 1.88 ms at 540p with nothing on, against
  0.43 ms for the `spin-sepulcher` timedemo at the same spawn. Probable
  cause (not verified): the live game advertises FTE particles, so AD shows
  its 1703 `misc_gtkmodel` decorations, which the demo (recorded with
  `sv_fteparticles 0`) lacks.
  Goggles costs are measured on that heavier base.
- **`spin-sepulcher.dem` is 133 MB** against 12 MB for the FTE version
  of the same map and length; worth a look in the recorder.

## Run time

The quick tier (vanilla demos, 3 rounds) took 9 minutes against 5; the
full run 71 against 30. A run takes ~15 s, mostly startup and map load
(timedemos themselves last 3–20 s). Options: quick runs at 540p only for
CPU-only changes (the plan allows it), shorter spin demos (120 s instead of
240), no attribution runs in quick mode, sharing one engine start across
several timedemos of the same game.

## Problems found while building it

- MangoHud couldn't write its log: the engine runs from the sandbox and
  the output dir was relative (`abs` only resolves existing paths); fixed
  by creating the dir first.
- `spin-e2m2` (the old water scene) spins at e2m2's spawn, where no water
  is in view; the first e2m2 pool view looked at a grate over a shallow
  channel (reflections changed ~450 pixels). Moved to e2m1's open pool.
- One-round runs marked any >3% change as significant (no spread); the
  report now shows "n/a (1 run)".

## Open decisions

- **Budgets** per feature (P4), e.g. the default tier at most X% of the 4K
  frame.
- **qprof**: the plan retires its scenarios, but it still has `-perf`
  per-function profiles of a measured window. Retire, or keep for `-perf`.
- **Run time**: which of the options above to take.
- **Next (P5)**: SSAO top, bloom and ray-traced water first by 4K cost.

## Reproduce

```sh
cargo build --release
target/release/perfkit record -only combat-e1m3,spin-e1m1,spin-e2m2,spin-sepulcher,spin-sepulcher-fte
target/release/perfkit run -full          # opens windows for ~70 min
target/release/perfkit run -list          # scenes; -dry shows the runs
```

Report: `target/perf/runs/<commit>/report.{md,json}`; this run's copy is
in `target/perf/baseline/` (not committed).
