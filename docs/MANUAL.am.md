# የተጠቃሚ መመሪያ

ይህ መመሪያ Quakeን በዚህ ፖርት መጫወትን ይሸፍናል፤ ትኩረቱም ፖርቱ ከመደበኛው
Quake እና ከሌሎች የምንጭ ፖርቶች በላይ በሚጨምራቸው ነገሮች ላይ ነው። አዲስ ነገር
ሁሉ አማራጭ ነው፦ በነባሪ ቅንብሮች ጨዋታው እንደ Quake ይታያል ይጫወታልም።

## መጀመር

1. የራስዎን የQuake ቅጂ ያግኙ። ፖርቱን `id1/` (እና ከጎኑ ያሉ ሞዶችን) ወደያዘው
   ማውጫ በ`QUAKE_BASEDIR` ወይም በ`-basedir <dir>` ይጠቁሙት።
2. `cargo run --release` ያስኪዱ፣ ወይም ሞድን በቀጥታ በ
   `-game <dir> +map <map>` ያስጀምሩ።
3. ቅንብሮች፣ ማስቀመጫዎችና ቅጽበታዊ ገጽ እይታዎች በ
   `~/.local/share/quake-source-port/<game>/` ውስጥ ይገኛሉ፤ ለእያንዳንዱ ሞድ አንድ አቃፊ።

ዋናው ምናሌ አንድ ተጫዋች፣ ብዙ ተጫዋቾች፣ አማራጮች፣ **እገዛ** (ይህ መመሪያ)፣
መውጫ እና **የካርታ ጥቅሎች** አሉት፤ ከጀርባውም የQuake ዜማ ይጫወታል
(አማራጮች → ድምፅ → የዋና ምናሌ ሙዚቃ)። እያንዳንዱ ምናሌ በአይጥ፣ በቁልፍ ሰሌዳ፣
በመቆጣጠሪያና በንክኪ ይሰራል፤ አማራጩን የሚያብራራ ማብራሪያ ለማየት በአማራጭ ላይ
ያንዣብቡ ወይም ይምረጡት።

በእገዛ ውስጥ ላይ/ታች ክፍል ይመርጣል፤ Page Up/Page Down፣ ግራ/ቀኝ፣ የትከሻ
አዝራሮች ወይም በጽሑፉ ላይ ያለው የአይጥ ጎማ ጽሑፉን ያሸበልላሉ።

## ቋንቋ

አማራጮች → ጨዋታ → **ቋንቋ** የምናሌዎችን፣ በስክሪን ላይ ያሉ መልዕክቶችንና የዚህን
መመሪያ ቋንቋ ይመርጣል፦ እንግሊዝኛ፣ ፈረንሳይኛ፣ ጀርመንኛ፣ ጣሊያንኛ፣ ስፓኒሽ፣
ሩሲያኛ፣ ፖላንድኛ፣ ዩክሬንኛ፣ ቼክኛ፣ ስሎቫክኛ፣ ክሮሽያኛ፣ ቡልጋሪኛ፣ ስዊድንኛ፣
ፊንላንድኛ፣ ዴንማርክኛ፣ ኖርዌይኛ፣ ደችኛ፣ ግሪክኛ፣ ሀንጋሪኛ፣ ሮማኒያኛ፣ ፖርቱጋልኛ
(ፖርቱጋል ወይም ብራዚል)፣ ጃፓንኛ፣ ኮሪያኛ፣ ቻይንኛ (ቀለል ያለ ወይም
ባህላዊ)፣ ቱርክኛ፣ ኢንዶኔዥያኛ፣ ማሌይኛ፣ ፊሊፒንኛ፣ ቬትናምኛ፣
ሰርቢያኛ፣ ሊቱዌኒያኛ፣ ላትቪያኛ፣ ኢስቶኒያኛ፣ ማልቲስኛ፣ አልባኒያኛ፣ አርመንኛ፣
ጆርጂያኛ፣ አይስላንድኛ፣ አይሪሽ፣ ዌልሽ፣ ባስክኛ፣ ካታላንኛ፣ ጋሊሺያኛ፣ ላቲን፣
ኤስፔራንቶ፣ ቤላሩስኛ፣ መቄዶንኛ፣ ስሎቬንኛ፣ ስዋሂሊ፣ ዓረብኛ፣ ዕብራይስጥ፣
ፋርስኛ፣ ኡርዱ፣ ሂንዲ፣ ማራቲ፣ ቤንጋሊኛ፣ ፑንጃቢ፣ ጉጃራቲ፣ ታሚልኛ፣ ቴሉጉ፣
ታይኛ፣ ክመርኛ፣ አማርኛ ወይም ካንቶኒዝ።
**ሲስተም** የኮምፒውተርዎን ቋንቋ ይከተላል። የ2021 ዳግም እትም የራሱ የጨዋታ ጽሑፍ
ወደ ፈረንሳይኛ፣ ጀርመንኛ፣ ጣሊያንኛ፣ ስፓኒሽና ሩሲያኛ ብቻ ተተርጉሟል፤ ሌሎች
ቋንቋዎች በእንግሊዝኛ ያሳዩታል። ከእንግሊዝኛ ውጭ ባሉ ቋንቋዎች ትንሹ የጨዋታ ውስጥ
ጽሑፍ የምናሌውን ፊደል ይጠቀማል፣ ምክንያቱም የክላሲኩ Quake ፊደል ያልተቀየሩ
የላቲን ፊደላትን ብቻ ይዟል። **ኮንሶሉን ተርጉም** ካልበራ በስተቀር የኮንሶል
መልዕክቶች በእንግሊዝኛ ይቆያሉ።

## የካርታ ጥቅሎች (የሞድ አሳሽ)

ዋና ምናሌ → የካርታ ጥቅሎች የተጫኑትን ሞዶችና የካርታ ጥቅሎች ሁሉ ከመግለጫቸው ጋር
ይዘረዝራል። ወደ አንዱ ለመቀየር ይምረጡት፣ ከዚያም ካርታዎቹን አስሰው ማንኛውንም
በቀጥታ ይጀምሩ። አሳሹ ለእያንዳንዱ ካርታ ምርጥ ግድያዎችዎን፣ ሚስጥሮችንና ጊዜን
ይከታተላል። እያንዳንዱ ሞድ የራሱን ቅንብሮች ይይዛል፣ ስለዚህ ለአንድ ሞድ የተስተካከሉ
ምደባዎችና ቅንብሮች ወደ ሌላው አይፈሱም።

**የካርታ ጥቅሎች የት ይቀመጣሉ።** ፖርቱ በQuake መሠረታዊ ማውጫ ውስጥ ይፈልጋቸዋል
(`id1/`ን የያዘው፣ በ`QUAKE_BASEDIR` ወይም በ`-basedir` የሚዘጋጀው)። እዚያ
ያለ የጨዋታ ውሂብ (`.pak` ወይም `.pk3` ፋይል፣ `progs.dat`፣ ወይም `maps/`
አቃፊ) የያዘ እያንዳንዱ ንዑስ አቃፊ ይዘረዘራል፤ ስለዚህ የካርታ ጥቅልን ከ`id1/` ጎን
ባለ የራሱ አቃፊ ውስጥ በመፍታት ይጫኑት፣ ለምሳሌ
`<basedir>/ad/` ወይም `<basedir>/my_maps/maps/*.bsp`። እንዴት እንደሚዘረዘር
ለመቆጣጠር፣ ከፈለጉ `title`፣ `base` እና `description` መስመሮች ያሉት
`modinfo.txt` ያክሉ። ጥቅሎች የሚገኙት ጨዋታው ሲጀምር ነው፣ ስለዚህ አንዱን ካከሉ
በኋላ እንደገና ያስጀምሩ። የእያንዳንዱ ጥቅል ማስቀመጫዎች፣ ቅጽበታዊ ገጽ እይታዎችና
ቅንብሮች በጥቅሉ አቃፊ ውስጥ ሳይሆን በ
`~/.local/share/quake-source-port/<folder>/` ውስጥ ይገኛሉ።

## መቆጣጠሪያዎች

ፖርቱ በጌምፓድ እንዲጫወት ተደርጎ የተነደፈ ነው።

- **የመሳሪያ ጎማ** (`+weaponwheel`)፦ ጊዜን ለማዘግየት ይያዙ፣ መሳሪያን በማንኛውም
  ስቲክ ወይም በአይጥ ይምረጡ፤ ለመቀየር ይልቀቁ።
- **የማነጣጠር እገዛ** (አማራጮች → ግቤት → መቆጣጠሪያ)፦ በጠላቶች አጠገብ ማዘግየትና
  እነሱን የሚከተል ማሽከርከር። የሚተገበረው በስቲኩ ላይ ብቻ ነው፣ በአይጥ ላይ
  ፈጽሞ አይደለም።
- **በጋይሮ ማነጣጠር** (አማራጮች → ግቤት → መቆጣጠሪያ → ጋይሮ)፦ ማብሪያ/ማጥፊያ፣
  እንዲሁም ለግራ-ቀኝ፣ ለላይ-ታች እና ለማዘንበል ዘንጎች የተለየ ትብነት (ማዘንበል
  በነባሪ ጠፍቷል፣ እይታውን እንደ ግራ-ቀኝ ያዞራል፣ አሉታዊ እሴቶች ይገለብጡታል)፣ የጫጫታ
  ማጣሪያ፣ እና ጋይሮ መቼ እንደሚሰራ (ሁልጊዜ፣ `+gyroaction` ሲያዝ ጠፍቶ፣ ወይም ሲያዝ
  ብቻ)። **የማነጣጠር ዘይቤ** የቀኝ ስቲኩን በ2D ማነጣጠር (እይታውን ያለማቋረጥ
  ያዞራል) እና በ**ፍሊክ ስቲክ** (እይታውን ወደዚያ አቅጣጫ ወዲያው ለማዞር ስቲኩን
  ይግፉ፣ ከዚያ ለማሽከርከር ስቲኩን ያዙሩ) መካከል ይቀያይራል፤ ሁለቱም ለትክክለኛ
  ማነጣጠር ከጋይሮ ጋር በደንብ ይጣመራሉ።
- **ንዝረት**፣ የስቲክ ትብነትና መገልበጥ።

አማራጮች → ማሻሻያዎች። ሁሉም በደንበኛው በኩል ናቸው፣ በነባሪም ጠፍተዋል፣ ስለዚህ
ከማንኛውም ሞድ ጋርና በመስመር ላይ ይሰራሉ።

- **ፍርስራሽ**፦ የሚንከባለሉ የአካል ቁርጥራጮችና ከተሰባበሩ በርሜሎች የሚወጡ ስብርባሪዎች፣
  ከሞድ ጭራቆችም ጋር፤ በሮችንና ሊፍቶችን ሊመታ ይችላል።
- **የተሻሻለ የደም ፍንጣቂ**፦ በገጽታዎች ላይ ፍንጣቂዎች፣ አካላትን የሚከተሉ ቁስሎች፣
  በሚያርፉበት የሚረጩ በአየር ላይ ያሉ ጠብታዎች።
- **የገጽ ምት ተጽዕኖዎች**፦ የሾትገን ጥይት ምልክቶች፣ በእንጨትና በጠላቶች ውስጥ
  የሚሰኩ ሚስማሮች፣ የፍንዳታ የቃጠሎ ምልክቶች።
- **የተሻሻለ ውሃ**፦ አሳላፊነት፣ ሞገዶች፣ ፍንጣቂዎችና የውሃ ብርሃን ነጸብራቅ።
- መድረሻቸውን በፓራላክስ የሚያሳዩ **አሳላፊ ቴሌፖርተሮች**።
- የአካባቢ ጥላ፣ በነገር እና በፍጥነት የእንቅስቃሴ ብዥታ፣ ለስላሳ ቅንጣቶች።
- **የስክሪን ሼደር**፦ የRetroArch `.slangp` ቅድመ-ቅንብሮች (CRT እና ሌሎች)።

አማራጮች → ግራፊክስ የተለመዱትን የማሳያ መጠን፣ ፀረ-ጥርስ፣ ሱፐርሳምፕሊንግ፣ የቴክስቸር
ማጣሪያ፣ 8-ቢት ቀለም ከዲተሪንግ ጋር፣ ጭጋግ፣ ባለቀለም ብርሃን እና የአኒሜሽን/የእንቅስቃሴ
ማለስለስን ይዟል።

## ተጨማሪዎች

ተጨማሪዎች በሞተሩ የሚሰሩ አዳዲስ መሳሪያዎችና ቁሳቁሶች ናቸው፣ ስለዚህ ከማንኛውም
ሞድ progs ጋር ይሰራሉ። ለአንድ ተጫዋችና ለትብብር ብቻ ናቸው።

### በተጨማሪዎች ጨዋታ መጀመር

ጨዋታ ተጨማሪዎች የሚኖሩት ከእነሱ ጋር ከጀመረ ብቻ ነው፦

1. አንድ ተጫዋች → የ**ተጨማሪዎች** ሳጥኑን ምልክት ያድርጉ፣ ከዚያም አዲስ ጨዋታ።
2. የትኞቹን ተጨማሪዎች እንደሚያመጡ ይምረጡና ቅንብሮቻቸውን ያስተካክሉ፣ ከዚያም አዲስ
   ጨዋታ ጀምር።

የተጨማሪ ጨዋታዎች ከ`.sav` ይልቅ እንደ `.qsa` ፋይሎች ይቀመጣሉ፣ ስለዚህ ሌሎች ፖርቶች
ሊጭኗቸው አይሞክሩም። የማስቀመጫ ካርዶች "ADD-ONS" የሚል ምልክት ያሳያሉ። መደበኛ
ማስቀመጫን መጫን ተጨማሪዎችን ያጠፋል። የተጨማሪ ጨዋታ ሲጫወቱ፣ የተጨማሪዎች ገጽ
(ኮንሶል፦ `menu_options addons`) እያንዳንዱን ተጨማሪ ያበራል ያጠፋልም፤ እያንዳንዱ የሚደጋገም ቅድመ እይታ፣
መመሪያዎች፣ ምደባዎቹና የራሱ ቅንብሮች አሉት።
