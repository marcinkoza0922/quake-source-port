# 使用手冊

呢本手冊講點樣用呢個移植版玩Quake，重點係佢比原版Quake同其他移植版多咗啲乜。所有新功能都係可選嘅：用預設設定嘅話，遊戲嘅樣同玩法都同Quake一樣。

## 開始玩

1. 準備你自己嘅Quake遊戲。用`QUAKE_BASEDIR`或者`-basedir <dir>`指向包含`id1/`嘅目錄（同埋擺喺隔籬嘅模組）。
2. 執行`cargo run --release`，或者用`-game <dir> +map <map>`直接開模組。
3. 設定、存檔同截圖會放喺`~/.local/share/quake-source-port/<game>/`，每個模組一個資料夾。

主選單有Single Player、Multiplayer、Options、**說明**（即係呢本手冊）、Quit同**地圖包**，背景會播Quake主題曲（Options → 聲音 → 主選單音樂）。所有選單都可以用滑鼠、鍵盤、手掣同觸控操作；將游標移到選項上面或者揀咗佢，就會見到解釋佢嘅提示。

喺說明入面，上／下揀章節；Page Up／Page Down、左／右、膊頭掣，或者喺文字上面碌滑鼠轆，都可以捲動內容。

## 語言

Options → 玩法 → **語言**可以揀選單、畫面訊息同呢本手冊嘅語言：英文、法文、德文、意大利文、西班牙文、俄文、波蘭文、烏克蘭文、捷克文、斯洛伐克文、克羅地亞文、保加利亞文、瑞典文、芬蘭文、丹麥文、挪威文、荷蘭文、希臘文、匈牙利文、羅馬尼亞文、葡萄牙文（葡萄牙或者巴西）、日文、韓文、中文（簡體或者繁體）、土耳其文、印尼文、馬來文、菲律賓文、越南文、塞爾維亞文、立陶宛文、拉脫維亞文、愛沙尼亞文、馬耳他文、阿爾巴尼亞文、亞美尼亞文、格魯吉亞文、冰島文、愛爾蘭文、威爾斯文、巴斯克文、加泰隆尼亞文、加利西亞文、拉丁文、世界語、白俄羅斯文、馬其頓文、斯洛文尼亞文、斯瓦希里文、阿拉伯文、希伯來文、波斯文、烏爾都文、印地文、馬拉地文、孟加拉文、旁遮普文、古吉拉特文、泰米爾文、泰盧固文、泰文、高棉文、阿姆哈拉文或者廣東話。**系統**會跟你部電腦嘅語言。2021年重製版本身嘅遊戲文字只有法文、德文、意大利文、西班牙文同俄文翻譯；其他語言會用英文顯示。英文以外嘅語言，遊戲入面嘅細字會用選單字型，因為經典Quake字型淨係得冇重音符號嘅拉丁字母。除非開咗**翻譯控制台**，否則控制台訊息會保持英文。

## 地圖包（模組瀏覽器）

主選單 → 地圖包會列出所有已安裝嘅模組同地圖包，連埋佢哋嘅介紹。揀一個就會轉過去，之後可以瀏覽入面嘅地圖，直接開始任何一張。瀏覽器會記低每張地圖你最好嘅殺敵數、秘密數同時間。每個模組都有自己嘅設定，所以為某個模組調好嘅按鍵綁定同設定唔會影響到其他模組。

**地圖包要放喺邊。**呢個移植版會喺Quake基礎目錄（即係有`id1/`嘅目錄，用`QUAKE_BASEDIR`或者`-basedir`設定）搵地圖包。嗰度每個有遊戲資料（`.pak`或者`.pk3`檔案、`progs.dat`，或者`maps/`資料夾）嘅子資料夾都會列出嚟，所以安裝地圖包只要將佢解壓到`id1/`隔籬一個獨立資料夾就得，例如`<basedir>/ad/`或者`<basedir>/my_maps/maps/*.bsp`。你亦可以加一個有`title`、`base`同`description`行嘅`modinfo.txt`，控制佢點樣列出。地圖包喺遊戲啟動時先會搵，所以加完要重新開遊戲。每個地圖包嘅存檔、截圖同設定放喺`~/.local/share/quake-source-port/<folder>/`，唔係放喺地圖包資料夾入面。

## 分割畫面

同一部機最多六個玩家，可以玩合作或者死鬥。

- Multiplayer → New Game → **本機玩家**設定幾多人玩。
- 每位玩家都有自己嘅視角、HUD、聲音同輸入裝置（玩家1用鍵盤同滑鼠，其他玩家每人一個手掣）。
- 畫面版面可以上下排、左右並排、2×2或者3×2（`r_splitscreen_layout`）。
- 每位玩家可以喺Multiplayer → Setup揀名同衫／褲顏色。

## 手掣

呢個移植版本身就係設計俾你用手掣玩。

- **武器輪盤**（`+weaponwheel`）：撳住會令時間慢落嚟，再用任何一支搖桿或者滑鼠揀武器；放手就轉武器。
- **輔助瞄準**（Options → 輸入 → 手掣）：近敵人時減慢，同埋跟住敵人轉向。只係作用於搖桿，永遠唔會作用於滑鼠。
- **陀螺儀瞄準**（Options → 輸入 → 手掣 → 陀螺儀）：一個開關，加上偏航、俯仰同翻滾軸各自嘅靈敏度（翻滾預設關閉，會好似偏航咁轉視角，負數就反轉）、雜訊過濾，同埋陀螺儀幾時生效（一直、撳住`+gyroaction`時關閉，或者淨係撳住時）。**瞄準方式**可以將右搖桿切換做2D瞄準（連續轉視角）或者**甩桿**（推搖桿令視角即刻轉去嗰個方向，再轉搖桿旋轉視角）；兩樣都好夾陀螺儀做精細瞄準。
- **震動**、搖桿靈敏度同反轉。
- **按鈕圖示**會自動偵測同配合你個手掣（Xbox、PlayStation、Nintendo）。
- 所有按鍵都可以喺Options → 控制重新綁定，用手掣操作都得。
- 觸控螢幕操作，大小、不透明度同視角速度都可以調。

## 存檔

- **自動存檔**同手動存檔、快速存檔分開輪替，所以永遠唔會覆蓋你自己嘅存檔。Options → 玩法 → 自動存檔設定可以揀保留幾多個同幾時存：入關時、定時、搵到一個秘密或者搵齊所有秘密時，同埋殺晒所有敵人時。
- 載入／儲存選單入面嘅**存檔卡**會顯示每個存檔嘅關卡、生命值、護甲、武器、鎖匙同殺敵數／秘密數。
- **死亡時**（Options → 玩法 → 死亡時），單人遊戲可以喺暫停選單問你點做、載入最新存檔、俾你揀存檔，或者重新開始關卡。

## 玩法同鏡頭

Options → 玩法：

- 視野60–130、視角晃動、武器後座力、一直跑。
- **鏡頭**：第一身、第三身，或者越膊頭視角（右邊或者左邊）。
- **武器模型**位置：中間、右、左或者隱藏。

## 自訂：玩法調整同附加功能

每場遊戲喺開始時就決定係*原版*定係*自訂*。New Game（同埋喺揀關卡或者地圖包揀關卡）會彈出一個視窗：**開始玩**就開始遊戲，**自訂遊戲體驗**就打開玩法調整同附加功能。只要有任何改動，開始玩就會標住**自訂**，而**停用所有修改**（Del、手掣X掣或者撳一下）會還原做冇附加功能嘅標準規則。原版遊戲會存做ironwail同vkQuake都載入到嘅一般`.sav`檔案；自訂遊戲就存做淨係呢個移植版先載入到嘅`.qsa`檔案（分割畫面同合作遊戲都係咁，因為其他移植版存唔到呢類遊戲）。玩緊自訂遊戲時，隨時都可以喺主選單 → 自訂改佢嘅玩法調整同附加功能；原版遊戲嘅規則就固定唔變。玩法調整適用於任何模組，喺死鬥會自動關閉。

- 難啲：受多啲傷害、敵人更硬淨、彈藥同生命值拾取少啲、2–4倍怪物、每關手槍開局、禁止手動存檔。
- 易啲：受少啲傷害、敵人弱啲、彈藥同生命值多啲、無限彈藥、生命值回復、冇跌落傷害、唔會遇溺、冇自身傷害、二段跳或者三段跳。

## 示範錄影

`record <name>`同`stop`會將示範錄影錄落你嘅用戶資料夾；`playdemo <name>`就播返佢。停止錄製之後，示範錄影會喺背景重寫，等ironwail同vkQuake都播到。如果模組用咗其他移植版顯示唔到嘅粒子效果，完整版本會保留做`<name>.qsd`（`playdemo <name>.qsd`）。`demo_convert <name>`可以轉換舊嘅示範錄影。

主選單 → 示範會列出你儲存咗嘅示範；喺 選項 → 示範 度開咗「自動錄示範」之後，仲會列出你玩過每一關嘅自動示範，欄位滿咗最舊嗰啲就會被取代。撳 K 保留，撳 E 匯出做影片，撳 Del 刪除。錯誤報告會附上而家呢關嘅自動示範。

播示範嗰陣，Space 暫停，撳住左或者右鍵倒帶或者快轉，上下鍵轉速度，PgUp 同 PgDn 跳 10 秒，Home 同 End 跳去開頭同下一張地圖。I 同 O 標記片段；E 將個片段（或者成個示範）匯出去 `videos` 資料夾。控制列會一直顯示；撳 H 或者「收埋」可以收埋佢，將滑鼠指去螢幕底邊會出一條可以叫返佢出嚟嘅橫條。撳啲掣，撳時間軸跳去嗰度，或者喺時間軸上面拖嚟標示片段；「匯出」會問影格率、尺寸、格式同檔案，仲有匯出標示咗嘅片段定係成個示範。

`capture` 喺遊戲入面開始或者停止錄影。影格率、格式同質素喺 選項 → 示範 → 錄影 度設定。影片要用 ffmpeg；冇嘅話，影格會儲存做 PNG 圖片同一個 WAV 檔案。

## 無障礙

Options → 無障礙：

- 減少動態效果同螢幕閃光強度。
- 色盲濾鏡。
- 可以自訂嘅準星：形狀、大小、外框，同埋瞄準目標或者殺敵時變色；可選嘅命中標記。
- **聲音字幕**同訊息設定（訊息同字幕）、文字縮放。
- 用切換（而唔係撳住）方式攻擊同跑。
- 可以令成個遊戲慢落嚟嘅遊戲速度滑桿。
- 自動瞄準，有鎖定指示，同埋錐角同射程設定。

## 強化功能

Options → 強化功能。全部喺用戶端運行，預設關閉，所以適用於任何模組，網上玩都用得。

- **碎片**：翻滾嘅碎肉同爆開油桶噴出嘅破片，模組嘅怪物都有；碎片會俾門同升降機撞到推開。
- **強化血跡飛濺**：表面上嘅血跡、跟住屍體嘅傷口，同埋喺半空跌落地濺開嘅血滴。
- **表面命中效果**：散彈彈孔、會插喺木同敵人身上嘅鐵釘、爆炸焦痕。
- **強化水面**：半透明、波紋、水花同焦散。
- **睇得穿嘅傳送點**，用視差效果顯示目的地。
- 環境光遮蔽、物件同速度動態模糊、柔和粒子。
- **螢幕著色器**：RetroArch `.slangp`預設組合（CRT等等）。

Options → 畫面仲有常見嘅渲染比例、反鋸齒、超取樣、材質過濾、加抖色嘅8位元色彩、霧、彩色光照，同埋動畫／移動插補。

## 附加功能

附加功能係由引擎運行嘅新武器同裝備，所以適用於任何模組嘅progs。只限單人同合作遊戲。

### 用附加功能開始遊戲

一場遊戲要喺開始時已經有附加功能先會有：

1. Single Player → 剔**附加功能**方格，然後揀New Game。
2. 揀要帶邊啲附加功能同調好佢哋嘅設定，然後開始新遊戲。

附加功能遊戲會存做`.qsa`檔案而唔係`.sav`，所以其他移植版唔會試圖載入。存檔卡會顯示「ADD-ONS」標記。載入一般存檔會關閉附加功能。玩緊附加功能遊戲時，附加功能頁面（控制台：`menu_options addons`）可以逐個開關附加功能；每個都有循環播放嘅預覽、操作說明、按鍵綁定同自己嘅設定。

### 武器

附加功能會放入一般嘅武器欄位（每個附加功能可以自己揀欄位，或者用欄位9同0），並會喺武器輪盤同HUD出現。射擊同副射擊就係你平時嘅攻擊掣。

| 附加功能 | 射擊 | 副射擊 | 彈藥 |
|---|---|---|---|
| **傳送門槍** | 放藍色傳送門 | 放橙色傳送門 | 冇 |
| **磁軌炮** | 貫穿彈頭，打中直線上所有嘢 | — | 2粒電池 |
| **鉤爪** | 勾住木、金屬、石或者敵人，將自己扯過去 | — | 冇 |
| **黏彈發射器** | 撳住儲力，放手發射 | 引爆 | 1發火箭 |
| **迴力鏢** | 撳住標記敵人，放手擲出；逐個擊暈目標 | 清除標記 | 冇 |
| **凝膠噴射器** | 藍色彈跳凝膠（會彈） | 橙色加速凝膠（變快） | 冇 |
| **高壓清洗機** | 長距離水柱，可以推開敵人同沖走凝膠 | 闊扇形水柱 | 冇 |

傳送門可以放喺平坦嘅地圖表面，你、怪物同擲出去嘅物件都可以帶住動量穿過。開咗**睇穿傳送門**之後，可以即時睇到另一邊嘅畫面，包括透過傳送門睇到嘅傳送門；質素、即時畫面數量、距離同遞歸深度都可以調。

### 裝備

裝備係用開關方式用，唔係拎喺手。打開**裝備輪盤**（`+equipwheel`），或者用`goggles cycle`逐個切換：

- **夜視**
- **熱能視覺**

## 多人遊戲

除咗區域網絡同互聯網嘅NetQuake對戰（協定15、666同999），呢個移植版仲可以連去**QuakeWorld**伺服器。Multiplayer → Join Game可以輸入地址或者搜尋區域網絡。支援用FTE腳本粒子嘅模組。

## 命令列同控制台

常用選項：`-basedir <dir>`、`-game <dir>`、`-hipnotic`／`-rogue`／`-quoth`、`-width <w>`、`-height <h>`、`-fullscreen`、`-window`，同埋喺啟動時執行控制台指令嘅`+command args`。控制台（`~`）接受一般嘅Quake指令同cvar。
