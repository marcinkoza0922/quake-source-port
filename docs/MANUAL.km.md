# សៀវភៅ​ណែនាំ​អ្នក​ប្រើ

សៀវភៅ​ណែនាំ​នេះ​ពន្យល់​ពី​ការ​លេង Quake ជាមួយ port នេះ ដោយ​ផ្ដោត​លើ​អ្វី​ដែល​វា​បន្ថែម​លើស Quake ដើម​និង source port ផ្សេង​ទៀត។ អ្វីៗ​ថ្មី​ទាំង​អស់​គឺ​ជា​ជម្រើស: ជាមួយ​ការ​កំណត់​លំនាំ​ដើម ហ្គេម​មើល​ទៅ​និង​លេង​ដូច Quake ដើម។

## ការ​ចាប់​ផ្ដើម

1. រក​ច្បាប់​ចម្លង Quake ផ្ទាល់​ខ្លួន​របស់​អ្នក។ ចង្អុល port ទៅ​ថត​ដែល​មាន `id1/` (និង mod ណា​មួយ​នៅ​ក្បែរ​វា) ដោយ `QUAKE_BASEDIR` ឬ `-basedir <dir>`។
2. ដំណើរ​ការ `cargo run --release` ឬ​ចាប់​ផ្ដើម mod មួយ​ភ្លាមៗ​ដោយ `-game <dir> +map <map>`។
3. ការ​កំណត់ ការ​រក្សា​ទុក និង​រូប​ថត​អេក្រង់​ស្ថិត​នៅ​ក្នុង `~/.local/share/quake-source-port/<game>/` មួយ​ថត​សម្រាប់ mod នីមួយៗ។

ម៉ឺនុយ​មេ​មាន អ្នក​លេង​ម្នាក់ អ្នក​លេង​ច្រើន​នាក់ ជម្រើស **ជំនួយ** (សៀវភៅ​ណែនាំ​នេះ) ចាក​ចេញ និង **កញ្ចប់​ផែនទី** ដោយ​មាន​បទ​ភ្លេង Quake ចាក់​នៅ​ពី​ក្រោយ (ជម្រើស → សំឡេង → តន្ត្រី​ម៉ឺនុយ​មេ)។ ម៉ឺនុយ​ទាំង​អស់​ដំណើរ​ការ​ជាមួយ​កណ្ដុរ ក្ដារ​ចុច ឧបករណ៍​បញ្ជា និង​ការ​ប៉ះ; ដាក់​កណ្ដុរ​លើ​ឬ​ជ្រើស​ជម្រើស​មួយ​ដើម្បី​មើល​ការ​ពន្យល់​ខ្លី​របស់​វា។

ក្នុង ជំនួយ ឡើង/ចុះ​ជ្រើស​ផ្នែក; Page Up/Page Down ឆ្វេង/ស្ដាំ ប៊ូតុង​ស្មា ឬ​កង់​កណ្ដុរ​លើ​អត្ថបទ​រំកិល​វា។

## កញ្ចប់​ផែនទី (កម្មវិធី​រុករក mod)

ម៉ឺនុយ​មេ → កញ្ចប់​ផែនទី​រាយ mod និង​កញ្ចប់​ផែនទី​ដែល​បាន​ដំឡើង​ទាំង​អស់​ជាមួយ​ការ​ពិពណ៌នា​របស់​វា។ ជ្រើស​មួយ​ដើម្បី​ប្ដូរ​ទៅ​វា រួច​រក​មើល​ផែនទី​របស់​វា​ហើយ​ចាប់​ផ្ដើម​ផែនទី​ណា​មួយ​ដោយ​ផ្ទាល់។ កម្មវិធី​រុករក​កត់​ត្រា​ការ​សម្លាប់ កន្លែង​សម្ងាត់ និង​ពេល​វេលា​ល្អ​បំផុត​របស់​អ្នក​សម្រាប់​ផែនទី​នីមួយៗ។ mod នីមួយៗ​រក្សា​ការ​កំណត់​ផ្ទាល់​ខ្លួន ដូច្នេះ​គ្រាប់​ចុច​និង​ការ​កំណត់​សម្រាប់ mod មួយ​មិន​ជ្រាប​ចូល mod មួយ​ទៀត​ទេ។

**កន្លែង​ដាក់​កញ្ចប់​ផែនទី។** port ស្វែង​រក​វា​ក្នុង​ថត​មូល​ដ្ឋាន Quake (ថត​ដែល​មាន `id1/` កំណត់​ដោយ `QUAKE_BASEDIR` ឬ `-basedir`)។ ថត​រង​នីមួយៗ​នៅ​ទី​នោះ​ដែល​មាន​ទិន្នន័យ​ហ្គេម (ឯកសារ `.pak` ឬ `.pk3`, `progs.dat` ឬ​ថត `maps/`) ត្រូវ​បាន​រាយ ដូច្នេះ​ដំឡើង​កញ្ចប់​ផែនទី​ដោយ​ពន្លា​វា​ទៅ​ក្នុង​ថត​ផ្ទាល់​ខ្លួន​នៅ​ក្បែរ `id1/` ឧទាហរណ៍ `<basedir>/ad/` ឬ `<basedir>/my_maps/maps/*.bsp`។ អ្នក​អាច​បន្ថែម `modinfo.txt` ដែល​មាន​បន្ទាត់ `title`, `base` និង `description` ដើម្បី​គ្រប់​គ្រង​របៀប​ដែល​វា​ត្រូវ​បាន​រាយ។ កញ្ចប់​ត្រូវ​បាន​រក​ឃើញ​ពេល​ហ្គេម​ចាប់​ផ្ដើម ដូច្នេះ​ចាប់​ផ្ដើម​ឡើង​វិញ​ក្រោយ​ពេល​បន្ថែម​កញ្ចប់​ថ្មី។ ការ​រក្សា​ទុក រូប​ថត​អេក្រង់ និង​ការ​កំណត់​សម្រាប់​កញ្ចប់​នីមួយៗ​ស្ថិត​នៅ​ក្នុង `~/.local/share/quake-source-port/<folder>/` មិន​មែន​ក្នុង​ថត​កញ្ចប់​ទេ។

## បំបែក​អេក្រង់

អ្នក​លេង​រហូត​ដល់​ប្រាំមួយ​នាក់​លើ​ម៉ាស៊ីន​តែ​មួយ ក្នុង​របៀប​សហការ​ឬ​ប្រយុទ្ធ​ស្លាប់។

- អ្នក​លេង​ច្រើន​នាក់ → ហ្គេម​ថ្មី → **អ្នក​លេង​ក្នុង​ម៉ាស៊ីន** កំណត់​ចំនួន​អ្នក​លេង។
- អ្នក​លេង​ម្នាក់ៗ​មាន​ទិដ្ឋភាព HUD សំឡេង និង​ឧបករណ៍​បញ្ចូល​ផ្ទាល់​ខ្លួន (ក្ដារ​ចុច​និង​កណ្ដុរ​សម្រាប់​អ្នក​លេង​ទី 1 និង​ឧបករណ៍​បញ្ជា​ម្នាក់​មួយ​សម្រាប់​អ្នក​ផ្សេង​ទៀត)។
- ប្លង់​អេក្រង់​អាច​ជា​ជាន់​គ្នា នៅ​ក្បែរ​គ្នា 2×2 ឬ 3×2 (`r_splitscreen_layout`)។
- អ្នក​លេង​ម្នាក់ៗ​ជ្រើស​ឈ្មោះ​និង​ពណ៌​អាវ/ខោ​នៅ អ្នក​លេង​ច្រើន​នាក់ → ការ​រៀបចំ។

## ឧបករណ៍​បញ្ជា

port នេះ​ត្រូវ​បាន​រចនា​ឡើង​ដើម្បី​លេង​ជាមួយ​ឧបករណ៍​បញ្ជា​ហ្គេម។

- **កង់​អាវុធ** (`+weaponwheel`): សង្កត់​ដើម្បី​បន្ថយ​ល្បឿន​ពេល​វេលា​ហើយ​ជ្រើស​អាវុធ​ដោយ​ដង​បញ្ជា​ណា​មួយ​ឬ​កណ្ដុរ; លែង​ដើម្បី​ប្ដូរ។
- **ជំនួយ​ការ​តម្រង់** (ជម្រើស → ការ​បញ្ចូល → ឧបករណ៍​បញ្ជា): បន្ថយ​ល្បឿន​ពេល​នៅ​ជិត​សត្រូវ​និង​ការ​បង្វិល​ដែល​តាម​ពួក​វា។ វា​អនុវត្ត​តែ​ចំពោះ​ដង​បញ្ជា​ប៉ុណ្ណោះ មិន​ដែល​អនុវត្ត​ចំពោះ​កណ្ដុរ​ទេ។
- **តម្រង់​ដោយ​ជីរ៉ូ** (ជម្រើស → ការ​បញ្ចូល → ឧបករណ៍​បញ្ជា → ជីរ៉ូ): ការ​បិទ/បើក ព្រម​ទាំង​ភាព​រសើប​ដាច់​ដោយ​ឡែក​សម្រាប់​អ័ក្ស yaw, pitch និង roll (roll បិទ​តាម​លំនាំ​ដើម​ហើយ​បង្វិល​ទិដ្ឋភាព​ដូច yaw តម្លៃ​អវិជ្ជមាន​បញ្ច្រាស​វា) តម្រង​សញ្ញា​រំខាន និង​ពេល​ដែល​ជីរ៉ូ​អនុវត្ត (ជានិច្ច បិទ ឬ​តែ​ពេល​សង្កត់ `+gyroaction`)។ **របៀប​តម្រង់** ប្ដូរ​ដង​បញ្ជា​ស្ដាំ​រវាង​ការ​តម្រង់ 2D (វា​បង្វិល​ទិដ្ឋភាព​ជា​បន្ត​បន្ទាប់) និង **ដង​បញ្ជា​ផ្លិច** (រុញ​ដង​បញ្ជា​ដើម្បី​បង្វែរ​ទិដ្ឋភាព​ភ្លាម​ទៅ​ទិស​នោះ រួច​បង្វិល​ដង​បញ្ជា​ដើម្បី​បង្វិល​វា); ទាំង​ពីរ​ប្រើ​រួម​ជាមួយ​ជីរ៉ូ​បាន​ល្អ​សម្រាប់​ការ​តម្រង់​ល្អិត។
- **ការ​ញ័រ** ភាព​រសើប​ដង​បញ្ជា និង​ការ​បញ្ច្រាស។

- កំណត់​គ្រាប់​ចុច​ទាំង​អស់​ឡើង​វិញ​នៅ ជម្រើស → ការ​បញ្ជា រួម​ទាំង​ពី​ឧបករណ៍​បញ្ជា។

## ការ​រក្សា​ទុក

- **ការ​រក្សា​ទុក​ស្វ័យ​ប្រវត្តិ** វិល​ជុំ​ដាច់​ដោយ​ឡែក​ពី​ការ​រក្សា​ទុក​ដោយ​ដៃ​និង​ការ​រក្សា​ទុក​រហ័ស ដូច្នេះ​វា​មិន​ដែល​សរសេរ​ជាន់​ការ​រក្សា​ទុក​របស់​អ្នក​ទេ។ ជម្រើស → ការ​លេង → ការ​កំណត់​រក្សា​ទុក​ស្វ័យ​ប្រវត្តិ ជ្រើស​ចំនួន​ដែល​ត្រូវ​រក្សា​និង​ពេល​ដែល​ត្រូវ​រក្សា​ទុក: ពេល​ចូល​វគ្គ តាម​ម៉ោង​កំណត់ ពេល​រក​ឃើញ​កន្លែង​សម្ងាត់​មួយ​ឬ​ទាំង​អស់ និង​ពេល​សម្លាប់​សត្រូវ​ទាំង​អស់។
- **កាត​រក្សា​ទុក** ក្នុង​ម៉ឺនុយ ផ្ទុក/រក្សា​ទុក បង្ហាញ​វគ្គ សុខភាព អាវ​ក្រោះ អាវុធ កូនសោ និង​ការ​សម្លាប់/កន្លែង​សម្ងាត់​នៃ​ការ​រក្សា​ទុក​នីមួយៗ។
- **ពេល​ស្លាប់** (ជម្រើស → ការ​លេង → ពេល​ស្លាប់) អ្នក​លេង​ម្នាក់​អាច​សួរ​ថា​ត្រូវ​ធ្វើ​អ្វី​ក្នុង​ម៉ឺនុយ​ដែល​ផ្អាក ផ្ទុក​ការ​រក្សា​ទុក​ចុង​ក្រោយ ឱ្យ​អ្នក​ជ្រើស​ការ​រក្សា​ទុក ឬ​ចាប់​ផ្ដើម​វគ្គ​ឡើង​វិញ។

## ការ​លេង​និង​កាមេរ៉ា

ជម្រើស → ការ​លេង:

- មុំ​មើល 60–130 ការ​យោល​ទិដ្ឋភាព ការ​រញ្ជួយ​កាំភ្លើង រត់​ជានិច្ច។
- **កាមេរ៉ា**: មនុស្ស​ទី​មួយ មនុស្ស​ទី​បី ឬ​ពី​លើ​ស្មា (ស្ដាំ​ឬ​ឆ្វេង)។

## ប្ដូរ​តាម​បំណង: កត្តា​កែប្រែ​ការ​លេង​និង​គ្រឿង​បន្ថែម
