# 用户手册

本手册介绍如何使用本移植版游玩 Quake，重点说明它相比原版 Quake 和其他源码移植版新增的内容。所有新功能都是可选的：使用默认设置时，游戏的画面和玩法与 Quake 原版一致。

## 入门

1. 准备一份你自己的 Quake。通过 `QUAKE_BASEDIR` 或 `-basedir <dir>` 将本移植版指向包含 `id1/`（以及旁边各个模组）的目录。
2. 运行 `cargo run --release`，或使用 `-game <dir> +map <map>` 直接启动某个模组。
3. 配置、存档和截图保存在 `~/.local/share/quake-source-port/<game>/` 中，每个模组一个文件夹。

主菜单包含 Single Player、Multiplayer、Options、**Help**（即本手册）、Quit 和**地图包**，背景播放 Quake 主题曲（Options → 音频 → **主菜单音乐**）。所有菜单都支持鼠标、键盘、手柄和触屏操作；将指针悬停在选项上或选中它，即可看到说明该选项的提示。

在帮助中，上/下选择章节；Page Up/Page Down、左/右、肩键或在文字上滚动鼠标滚轮均可滚动内容。

## 语言

Options → 游戏性 → **语言**用于选择菜单、屏幕消息和本手册的语言：英语、法语、德语、意大利语、西班牙语、俄语、波兰语、乌克兰语、捷克语、斯洛伐克语、克罗地亚语、保加利亚语、瑞典语、芬兰语、丹麦语、挪威语、荷兰语、希腊语、匈牙利语、罗马尼亚语、葡萄牙语（葡萄牙或巴西）、日语、韩语、中文（简体或繁体）、土耳其语、印度尼西亚语、马来语、菲律宾语、越南语、塞尔维亚语、立陶宛语、拉脱维亚语、爱沙尼亚语、马耳他语、阿尔巴尼亚语、亚美尼亚语、格鲁吉亚语、冰岛语、爱尔兰语、威尔士语、巴斯克语、加泰罗尼亚语、加利西亚语、拉丁语、世界语、白俄罗斯语、马其顿语、斯洛文尼亚语、斯瓦希里语、阿拉伯语、希伯来语、波斯语、乌尔都语、印地语、马拉地语、孟加拉语、旁遮普语、古吉拉特语、泰米尔语、泰卢固语、泰语、高棉语、阿姆哈拉语或粤语。**系统**将跟随电脑的语言。2021 重制版自带的游戏文本仅翻译为法语、德语、意大利语、西班牙语和俄语；其他语言下这些文本以英文显示。在英语以外的语言中，游戏内的小号文字使用菜单字体，因为经典 Quake 字体只包含不带重音符号的拉丁字母。控制台消息保持英文，除非开启了**翻译控制台**。

## 地图包（模组浏览器）

主菜单 → 地图包会列出所有已安装的模组和地图包及其简介。选择其中一个即可切换过去，然后浏览它的地图并直接开始任意一张。浏览器会记录每张地图的最佳击杀数、秘密数和用时。每个模组都有独立的配置，因此为某个模组调整的按键绑定和设置不会影响其他模组。

**地图包放在哪里。**本移植版会在 Quake 基础目录（包含 `id1/` 的目录，由 `QUAKE_BASEDIR` 或 `-basedir` 设置）中查找。该目录下每个包含游戏数据（`.pak` 或 `.pk3` 文件、`progs.dat` 或 `maps/` 文件夹）的子文件夹都会被列出，因此安装地图包时，只需将其解压到 `id1/` 旁边的独立文件夹中，例如 `<basedir>/ad/` 或 `<basedir>/my_maps/maps/*.bsp`。也可以添加一个包含 `title`、`base` 和 `description` 行的 `modinfo.txt` 来控制它的显示方式。地图包在游戏启动时被识别，因此添加后需要重启游戏。每个地图包的存档、截图和配置保存在 `~/.local/share/quake-source-port/<folder>/` 中，而不是地图包文件夹里。

## 分屏

一台机器上最多支持六名玩家，可进行合作或死亡竞赛。

- Multiplayer → New Game → **本地玩家**设置参与游戏的人数。
- 每位玩家都有自己的视角、HUD、声音和输入设备（玩家 1 使用键盘和鼠标，其余玩家各用一个手柄）。
- 屏幕布局可以是上下堆叠、左右并排、2×2 或 3×2（`r_splitscreen_layout`）。
- 每位玩家可在 Multiplayer → Setup 中选择名字以及上衣和裤子颜色。

## 手柄

本移植版专为手柄游玩而设计。

- **武器轮盘**（`+weaponwheel`）：按住时放慢时间，用任一摇杆或鼠标选择武器；松开即切换。
- **辅助瞄准**（Options → 输入 → 手柄）：靠近敌人时减速，并跟随敌人转动视角。它只作用于摇杆，绝不作用于鼠标。
- **陀螺仪瞄准**（Options → 输入 → 手柄 → 陀螺仪）：一个开关，外加偏航、俯仰和横滚三个轴的独立灵敏度（横滚默认关闭，会像偏航一样转动视角，负值则反向）、降噪滤波，以及陀螺仪的生效时机（始终、按住 `+gyroaction` 时关闭，或仅在按住时生效）。**瞄准方式**可将右摇杆在 2D 瞄准（持续转动视角）和**甩动摇杆**（推动摇杆使视角立即转向该方向，然后转动摇杆旋转视角）之间切换；两者都能与陀螺仪很好地配合进行精确瞄准。
- **震动**、摇杆灵敏度和反转。
- **按键图标**与你的手柄（Xbox、PlayStation、任天堂）相匹配，并会自动检测。
- 可在 Options → 控制 中重新绑定所有按键，也可以直接用手柄操作。
- 触屏控制，可调整大小、不透明度和视角速度。

## 存档

- **自动存档**与手动存档和快速存档分开轮换，因此绝不会覆盖你自己的存档。Options → 游戏性 → **自动存档设置**可选择保留的数量以及存档时机：进入关卡时、定时、找到一个秘密或所有秘密时，以及消灭所有敌人时。
- 载入/保存菜单中的**存档卡片**会显示每个存档的关卡、生命值、护甲、武器、钥匙以及击杀数/秘密数。
- **死亡时**（Options → 游戏性 → **死亡时**），单人游戏可以在暂停菜单中询问如何处理、载入最新存档、让你选择存档，或重新开始关卡。

## 游戏性与镜头

Options → 游戏性：

- 视野 60–130、视角晃动、武器后坐、总是奔跑。
- **镜头**：第一人称、第三人称或越肩视角（右肩或左肩）。
- **武器模型**位置：居中、右侧、左侧或隐藏。

## 自定义：游戏修改项与附加功能

一局游戏要么是*原版*，要么是*自定义*，在开始时决定。新游戏（以及在选择关卡或地图包中选择关卡时）会显示一个弹窗：**开始**直接开始游戏，**自定义体验**打开游戏修改项和附加功能。只要有任何更改，“开始”就会标上**自定义**，而**禁用所有修改**（Del、手柄 X 键或点击）会恢复无附加功能的标准规则。原版游戏保存为 ironwail 和 vkQuake 也能载入的普通 `.sav` 文件；自定义游戏保存为只有本移植版能载入的 `.qsa` 文件（分屏和合作游戏也是如此，因为其他移植版无法保存它们）。在自定义游戏中，可随时通过主菜单 → **自定义**更改其修改项和附加功能；原版游戏的规则则保持固定。修改项适用于任何模组，在死亡竞赛中会自动关闭。

- 更难：受到更多伤害、敌人更强、拾取的弹药和生命更少、2–4 倍怪物、每关手枪开局、禁止手动存档。
- 更易：受到更少伤害、敌人更弱、弹药和生命更多、无限弹药、生命值恢复、无坠落伤害、不会溺水、无自身伤害、二段跳或三段跳。

## 录像

`record <name>` 和 `stop` 将录像录制到你的用户文件夹中；`playdemo <name>` 播放录像。录制停止后，录像会在后台重写，使 ironwail 和 vkQuake 也能播放。如果模组使用了其他移植版无法显示的粒子效果，完整版本会另存为 `<name>.qsd`（`playdemo <name>.qsd`）。`demo_convert <name>` 可转换旧录像。

## 辅助功能

Options → 辅助功能：

- 减少动态效果和屏幕闪光强度。
- 色盲滤镜。
- 可配置的准星：形状、大小、描边，以及瞄准目标或击杀时变色；可选的命中标记。
- **音效字幕**和消息设置（**消息与字幕**），文字缩放。
- 切换式（而非按住式）攻击和奔跑。
- 用于放慢整个游戏的游戏速度滑块。
- 带锁定指示器、锥角和射程设置的自动瞄准。

## 增强效果

Options → 增强效果。全部在客户端运行且默认关闭，因此适用于任何模组，也可联机使用。

- **碎片**：翻滚的碎肉以及爆裂木桶飞出的弹片，模组怪物同样适用；碎片会撞到门和升降梯上。
- **增强血液**：表面上的血迹飞溅、跟随躯体的伤口，以及落地处溅开的空中血滴。
- **命中效果**：霰弹弹痕、钉在木头和敌人身上的钉子、爆炸焦痕。
- **增强水面**：半透明、波纹、水花和焦散。
- **透视传送点**：以视差效果显示目的地。
- 环境光遮蔽、按物体和按速度的动态模糊、柔和粒子。
- **屏幕着色器**：RetroArch `.slangp` 预设（CRT 等）。

Options → 图形 还提供常见的渲染缩放、抗锯齿、超级采样、纹理过滤、带抖动的 8 位色彩、雾、彩色光照以及动画/移动插值。

## 附加功能

附加功能是由引擎运行的新武器和装备，因此适用于任何模组的 progs。它们仅限单人游戏和合作模式。

### 以附加功能开始游戏

只有在开始时启用了附加功能的游戏才会拥有它们：

1. Single Player → 勾选**附加功能**复选框，然后选择 New Game。
2. 选择要带上的附加功能并调整其设置，然后开始新游戏。

附加功能游戏保存为 `.qsa` 文件而不是 `.sav`，因此其他移植版不会尝试载入它们。存档卡片上会显示“ADD-ONS”标记。载入普通存档会关闭附加功能。在附加功能游戏中，附加功能页面（控制台：`menu_options addons`）可以单独开启或关闭每个附加功能；每个附加功能都有循环播放的预览、说明、按键绑定和独立设置。

### 武器

附加功能放入常规武器槽（可为每个附加功能单独选择，或使用 9 号和 0 号槽），并显示在武器轮盘和 HUD 上。开火和副开火就是你平常的攻击键。

| 附加功能 | 开火 | 副开火 | 弹药 |
|---|---|---|---|
| **传送门枪** | 放置蓝色传送门 | 放置橙色传送门 | 无 |
| **轨道炮** | 贯穿弹，命中直线上的所有目标 | — | 2 个电池 |
| **钩爪** | 钩住木头、金属、石头或敌人并将自己拉过去 | — | 无 |
| **粘弹发射器** | 按住蓄力，松开发射 | 引爆 | 1 枚火箭弹 |
| **回旋镖** | 按住标记敌人，松开投掷；依次眩晕每个目标 | 清除标记 | 无 |
| **凝胶喷射器** | 蓝色排斥凝胶（弹跳） | 橙色推进凝胶（加速） | 无 |
| **高压水枪** | 长距离水柱，可推开敌人并冲掉凝胶 | 宽幅扇形水流 | 无 |

传送门可放置在平坦的地图表面上，你、怪物和投掷物穿过时都会保留动量。开启**透过传送门观看**后，你可以实时看到另一侧的画面，包括透过传送门看到的其他传送门；画面质量、实时画面数量、距离和递归深度均可调整。

### 装备

装备是开启和关闭的，而不是手持使用。打开**装备轮盘**（`+equipwheel`），或使用 `goggles cycle` 依次切换：

- **夜视**
- **热成像**

## 多人游戏

除了局域网和互联网 NetQuake 联机（协议 15、666 和 999）外，本移植版还能连接 **QuakeWorld** 服务器。Multiplayer → Join Game 可以输入地址或搜索局域网。对于使用 FTE 脚本粒子的模组，也提供支持。

## 命令行与控制台

常用选项：`-basedir <dir>`、`-game <dir>`、`-hipnotic` / `-rogue` / `-quoth`、`-width <w>`、`-height <h>`、`-fullscreen`、`-window`，以及在启动时运行控制台命令的 `+command args`。控制台（`~`）支持常用的 Quake 命令和控制台变量。
