# 使用手冊

本手冊說明如何使用本移植版遊玩Quake，重點在於它相較於原版Quake與其他移植版新增的功能。所有新功能都是選用的：在預設設定下，遊戲的外觀與玩法都和Quake一樣。

## 開始使用

1. 準備你自己的Quake遊戲。用`QUAKE_BASEDIR`或`-basedir <dir>`指定包含`id1/`的目錄（以及放在旁邊的模組）。
2. 執行`cargo run --release`，或用`-game <dir> +map <map>`直接啟動模組。
3. 設定、存檔與螢幕截圖存放在`~/.local/share/quake-source-port/<game>/`，每個模組各有一個資料夾。

主選單包含Single Player、Multiplayer、Options、**Help**（本手冊）、Quit與**地圖包**，背景會播放Quake主題曲（Options → 音效 → 主選單音樂）。所有選單都支援滑鼠、鍵盤、手把與觸控操作；將游標移到選項上或選取選項，即可看到說明提示。

在Help中，上／下選擇章節；Page Up／Page Down、左／右、肩部按鈕或在文字上捲動滑鼠滾輪即可捲動內容。

## 語言

Options → 遊戲玩法 → **語言**可選擇選單、畫面訊息與本手冊的語言：英文、法文、德文、義大利文、西班牙文、俄文、波蘭文、烏克蘭文、捷克文、斯洛伐克文、克羅埃西亞文、保加利亞文、瑞典文、芬蘭文、丹麥文、挪威文、荷蘭文、希臘文、匈牙利文、羅馬尼亞文、葡萄牙文（葡萄牙或巴西）、日文、韓文、中文（簡體或繁體）、土耳其文、印尼文、馬來文、菲律賓文、越南文、塞爾維亞文、立陶宛文、拉脫維亞文、愛沙尼亞文、馬爾他文、阿爾巴尼亞文、亞美尼亞文、喬治亞文、冰島文、愛爾蘭文、威爾斯文、巴斯克文、加泰隆尼亞文、加利西亞文、拉丁文、世界語、白俄羅斯文、馬其頓文、斯洛維尼亞文、史瓦希里文、阿拉伯文、希伯來文、波斯文、烏爾都文、印地文、馬拉地文、孟加拉文、旁遮普文、古吉拉特文、坦米爾文、泰盧固文、泰文、高棉文、阿姆哈拉文或粵語。**系統**會依照電腦的語言設定。2021年重製版本身的遊戲文字只有法文、德文、義大利文、西班牙文與俄文翻譯；其他語言會以英文顯示。英文以外的語言中，遊戲內的小型文字會使用選單字型，因為經典Quake字型只有不含重音符號的拉丁字母。除非開啟**翻譯主控台**，否則主控台訊息會維持英文。

## 地圖包（模組瀏覽器）

主選單 → 地圖包會列出所有已安裝的模組與地圖包及其說明。選擇其中一個即可切換過去，接著瀏覽其中的地圖並直接開始任何一張。瀏覽器會記錄每張地圖的最佳擊殺數、秘密數與時間。每個模組都有自己的設定，因此為某個模組調整的按鍵綁定與設定不會影響其他模組。

**地圖包要放在哪裡。**本移植版會在Quake基礎目錄（包含`id1/`的目錄，用`QUAKE_BASEDIR`或`-basedir`設定）中尋找地圖包。該目錄下所有含有遊戲資料（`.pak`或`.pk3`檔案、`progs.dat`或`maps/`資料夾）的子資料夾都會列出，因此安裝地圖包時，只要將它解壓縮到`id1/`旁的獨立資料夾即可，例如`<basedir>/ad/`或`<basedir>/my_maps/maps/*.bsp`。也可以加入含有`title`、`base`與`description`行的`modinfo.txt`來控制列出的方式。地圖包會在遊戲啟動時偵測，因此加入後請重新啟動。每個地圖包的存檔、螢幕截圖與設定存放在`~/.local/share/quake-source-port/<folder>/`，而不是地圖包的資料夾中。

## 分割畫面

同一台電腦最多可供六名玩家進行合作或死鬥。

- Multiplayer → New Game → **本機玩家**設定遊玩人數。
- 每位玩家都有自己的視角、HUD、音效與輸入裝置（玩家1使用鍵盤與滑鼠，其他玩家各使用一支手把）。
- 畫面配置可以是上下排列、左右並排、2×2或3×2（`r_splitscreen_layout`）。
- 每位玩家可在Multiplayer → Setup中設定名稱與上衣／褲子顏色。

## 手把

本移植版的設計就是為了用手把遊玩。

- **武器輪盤**（`+weaponwheel`）：按住即可讓時間變慢，並用任一搖桿或滑鼠選擇武器；放開即切換。
- **輔助瞄準**（Options → 輸入 → 手把）：靠近敵人時減速，並跟隨敵人轉向。只作用於搖桿，絕不作用於滑鼠。
- **陀螺儀瞄準**（Options → 輸入 → 手把 → 陀螺儀）：一個開關，加上偏航、俯仰與滾轉軸各自的靈敏度（滾轉預設關閉，會像偏航一樣轉動視角，負值則反轉）、雜訊過濾，以及陀螺儀的作用時機（永遠、按住`+gyroaction`時關閉，或僅在按住時）。**瞄準方式**可將右搖桿切換為2D瞄準（連續轉動視角）或**甩桿**（推動搖桿讓視角立即轉向該方向，再轉動搖桿旋轉視角）；兩者與陀螺儀搭配都很適合精細瞄準。
- **震動**、搖桿靈敏度與反轉。
- **按鈕圖示**會自動偵測並配合你的手把（Xbox、PlayStation、Nintendo）。
- 所有按鍵都可在Options → 控制中重新綁定，也可以直接用手把操作。
- **Select / View ×2**: 螢幕截圖; **Start ×2**: 快速存檔; **Start** (按住): 快速載入。
- 觸控螢幕操作，可調整大小、不透明度與視角速度。

## 存檔

- **自動存檔**與手動存檔、快速存檔分開輪替，因此絕不會覆寫你自己的存檔。Options → 遊戲玩法 → 自動存檔設定可選擇保留數量與存檔時機：進入關卡時、定時、找到一個秘密或所有秘密時，以及消滅所有敵人時。
- 載入／儲存選單中的**存檔卡片**會顯示每個存檔的關卡、生命值、護甲、武器、鑰匙與擊殺數／秘密數。
- **死亡時**（Options → 遊戲玩法 → 死亡時），單人遊戲可以在暫停選單中詢問要怎麼做、載入最新存檔、讓你選擇存檔，或重新開始關卡。

## 遊戲玩法與鏡頭

Options → 遊戲玩法：

- 視野60–130、視角晃動、武器後座力、永遠奔跑。
- **鏡頭**：第一人稱、第三人稱，或越肩視角（右肩或左肩）。
- **武器模型**位置：置中、右、左或隱藏。

## 自訂：玩法調整與附加功能

每場遊戲在開始時就決定是*原版*還是*自訂*。New Game（以及在選擇關卡或地圖包中選擇關卡）會顯示一個彈出視窗：**遊玩**開始遊戲，**自訂遊戲體驗**則開啟玩法調整與附加功能。只要有任何變更，遊玩就會標上**自訂**，而**停用所有修改**（Del、手把X鍵或點擊）會恢復為沒有附加功能的標準規則。原版遊戲會儲存為ironwail與vkQuake也能載入的一般`.sav`檔案；自訂遊戲則儲存為只有本移植版能載入的`.qsa`檔案（分割畫面與合作遊戲也是如此，因為其他移植版無法儲存這類遊戲）。在自訂遊戲中，可隨時透過主選單 → 自訂變更玩法調整與附加功能；原版遊戲的規則則固定不變。玩法調整適用於任何模組，並會在死鬥中關閉。

- 更困難：承受更多傷害、更強悍的敵人、更少的彈藥與生命值拾取、2–4倍怪物、每個關卡手槍開局、禁止手動存檔。
- 更簡單：承受較少傷害、較弱的敵人、更多彈藥與生命值、無限彈藥、生命值回復、無墜落傷害、不會溺水、無自身傷害、二段跳或三段跳。

## 示範錄影

`record <name>`與`stop`會將示範錄影錄製到你的使用者資料夾；`playdemo <name>`可播放它。停止錄製後，示範錄影會在背景重新寫入，讓ironwail與vkQuake也能播放。如果模組使用了其他移植版無法顯示的粒子效果，完整版本會保留為`<name>.qsd`（`playdemo <name>.qsd`）。`demo_convert <name>`可轉換較舊的示範錄影。

主選單 → 示範列出你儲存的示範；在 選項 → 示範 中開啟「自動錄製示範」後，還會列出你玩過的每一關的自動示範，欄位滿時最舊的會被取代。輸入文字可篩選清單，按 Tab 切換排序；清單旁的按鈕可播放、匯出、重新命名、保留或刪除所選示範，重新命名自動示範即會保留它。錯誤回報會附上目前關卡的自動示範。

播放示範時，Space 暫停，按住左或右鍵倒轉或快轉，上下鍵改變速度，PgUp 和 PgDn 跳過 10 秒，Home 和 End 跳到開頭和下一張地圖。I 和 O 標記片段；E 把該片段（或整個示範）匯出到 `videos` 資料夾。控制列會一直顯示；按 H 或「隱藏」可隱藏，把滑鼠指向螢幕底邊會出現一條可把它叫回來的橫條。點擊按鈕，點擊時間軸跳到該處，或在時間軸上拖曳來標示片段；「匯出」會詢問影格率、尺寸、格式和檔案，以及匯出標示的片段還是整個示範。

使用控制器時，A 暫停，方向鍵倒轉、快轉和改變速度，LB 和 RB 跳轉 10 秒，按下搖桿跳到開頭和下一張地圖。LT 和 RT 標記片段，B 清除標記，X 匯出，Y 保留自動示範，View 隱藏控制列。

`capture` 在遊戲中開始或停止錄製影片。影格率、格式和品質在 選項 → 示範 → 影片錄製 中設定。影片需要 ffmpeg；沒有它時，影格會儲存為 PNG 圖片和一個 WAV 檔案。

## 協助工具

Options → 協助工具：

- 減少動態效果與螢幕閃光強度。
- 色盲濾鏡。
- 可自訂的準星：形狀、大小、外框，以及瞄準目標或擊殺時變色；可選的命中標記。
- **音效字幕**；訊息和字幕的位置、大小和顯示時間在 HUD 編輯器中設定。
- 以切換（而非按住）方式攻擊與奔跑。
- 可讓整個遊戲變慢的遊戲速度滑桿。
- 自動瞄準，附鎖定指示，以及錐角與射程設定。

## 強化功能

Options → 強化功能。全部在用戶端執行且預設關閉，因此適用於任何模組，也能在線上使用。

- **碎片**：翻滾的碎肉與破碎油桶噴出的破片，也適用於模組的怪物；碎片會受到門與升降梯推動。
- **強化血液**：表面上的血跡飛濺、跟隨屍體的傷口，以及落地時濺開的空中血滴。
- **命中效果**：霰彈彈孔、會插在木頭與敵人身上的鐵釘、爆炸焦痕。
- **強化水面**：半透明、波紋、水花與焦散；**水下折射**、**畫面水滴**。
- **可透視的傳送點**，以視差效果顯示目的地。
- 環境光遮蔽、物體與速度動態模糊、柔和粒子。
- **螢幕著色器**：RetroArch `.slangp`預設組合（CRT等）。

Options → 畫面也有常見的渲染比例、反鋸齒、超取樣、材質過濾、附抖色的8位元色彩、霧、彩色光照，以及動畫／移動插補。

## 附加功能

附加功能是由引擎執行的新武器與裝備，因此適用於任何模組的progs。僅限單人與合作遊戲。

### 以附加功能開始遊戲

只有在開始時就啟用附加功能的遊戲才會有附加功能：

1. Single Player → 勾選**附加功能**核取方塊，然後選擇New Game。
2. 選擇要帶入的附加功能並調整其設定，然後開始新遊戲。

附加功能遊戲會儲存為`.qsa`檔案而非`.sav`，因此其他移植版不會嘗試載入。存檔卡片會顯示「ADD-ONS」標記。載入一般存檔會關閉附加功能。在附加功能遊戲中，附加功能頁面（主控台：`menu_options addons`）可個別開啟或關閉附加功能；每項都有循環播放的預覽、操作說明、按鍵綁定與專屬設定。

### 武器

附加功能會放入一般的武器欄位（可為每項附加功能選擇欄位，或使用欄位9與0），並出現在武器輪盤與HUD上。射擊與次要射擊就是你平常的攻擊按鍵。

| 附加功能 | 射擊 | 次要射擊 | 彈藥 |
|---|---|---|---|
| **傳送門槍** | 放置藍色傳送門 | 放置橘色傳送門 | 無 |
| **磁軌砲** | 貫穿彈頭，命中直線上的一切 | — | 2個電池 |
| **鉤爪** | 勾住木頭、金屬、石頭或敵人並把自己拉過去 | — | 無 |
| **黏彈發射器** | 按住蓄力，放開發射 | 引爆 | 1發火箭彈 |
| **迴力鏢** | 按住標記敵人，放開投擲；依序擊暈每個目標 | 清除標記 | 無 |
| **凝膠噴射器** | 藍色彈跳凝膠（會反彈） | 橘色加速凝膠（變快） | 無 |
| **高壓清洗機** | 長距離水柱，可推動敵人並沖掉凝膠 | 寬扇形水柱 | 無 |
| **公對公線纜** | 對觸手可及的發光電子面板使用副開火可插入一端；另一端隨即以無限彈藥發射閃電 | 副開火或切換武器會將其拔出 | 無 |
| **雙持手槍** | 左 | 右 | 無 (裝填: R) |
| **突擊步槍** | 使用你的鐵釘裝填的全自動步槍 | 次要射擊透過紅點瞄具瞄準，射擊更精準，視角更近 | 鐵釘 (裝填: R) |

傳送門可放置在平坦的地圖表面上，你、怪物與拋出的物體都能保持動量穿越。開啟**透視傳送門**後，可即時看到另一側的畫面，包括透過傳送門看到的傳送門；品質、即時畫面數量、距離與遞迴深度皆可調整。

## 多人遊戲

除了區域網路與網際網路的NetQuake對戰（協定15、666與999）之外，本移植版也能連線至**QuakeWorld**伺服器。Multiplayer → Join Game可輸入位址或搜尋區域網路。支援使用FTE腳本粒子的模組。

## 命令列與主控台

常用選項：`-basedir <dir>`、`-game <dir>`、`-hipnotic`／`-rogue`／`-quoth`、`-width <w>`、`-height <h>`、`-fullscreen`、`-window`，以及在啟動時執行主控台指令的`+command args`。主控台（`~`）接受一般的Quake指令與cvar。
